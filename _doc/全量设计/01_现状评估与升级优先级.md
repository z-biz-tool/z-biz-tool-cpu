## 1. 已经具备的价值

| 领域 | 当前事实 | 升级判断 |
|---|---|---|
| 技术栈 | React、TypeScript、Vite、Zustand、Ant Design | 保留主栈，避免无收益重写 |
| 内核 | 元件注册、网络展平、位宽推断、逐拍执行 | 有完整基础，需要明确语义与加固 |
| 编辑 | 放置、连线、选择、变换、封装、层级进入 | 补齐事务一致性、运行实例观察和恢复 |
| 学习 | 五层 31 关、提示、参考解答、成本和成就 | 优先精修课程反馈，不先扩充题量 |
| 汇编与 CPU | Z16 汇编器、参考 CPU、7 个示例 | 可作为计算机教学闭环，先统一语义 |
| 保存 | localStorage 与 JSON 导入导出 | 是设计存档，不是完整项目或运行现场 |
| 调试 | 探针当前值、日志、参考 CPU 状态 | 没有真正历史波形与确定性回放 |
| 测试 | 自检脚本含 41 个顶层检查 | 保留资产，补边界、恶意输入及浏览器测试 |

[README](../../README.md)与当前源码存在少量口径差异，例如元件数。产品材料由注册表生成数量；首发验收不依赖手写宣传数字。不能把现有二态逐拍执行宣传成任意精度、真实传播延迟仿真。

### 关联风险

- [custom.ts](../../src/core/custom.ts#L108-L136) 中成本递归没有和网表展开一致的循环防护，不能只保护仿真入口。
- [registry.ts](../../src/core/registry.ts#L701-L712) 中存储规模取自参数；界面的范围提示不能代替导入后的运行时校验。
- [sim.ts](../../src/core/sim.ts#L282-L309) 的固定时钟扫描不足以覆盖所有派生时钟事件；这是新调度器的重点回归场景。
- [verify.ts](../../scripts/verify.ts#L356-L393) 的聚合测试可跳过缺失参考解答；“剩余解答全过”不能等同于“所有关卡齐全”。

## 3. 目前不能作出的产品承诺

1. 不能把探针表称为历史波形。
2. 不能把浅状态拷贝称为可靠时间旅行。
3. 不能把一个计数程序成功称为完整 ISA 正确。
4. 不能把教学成本称为真实面积、功耗或频率。
5. 不能把浏览器成绩称为可信考试结果。
6. 不能把浮空信号归零称为物理电路真实行为。
7. 不能根据 README 或组件总量宣称大型电路性能已验证。
8. 不能把不同层级的定义重新运行当作观察主电路中的那个实例。

## 4. 升级优先级矩阵

| 顺序 | 交付价值 | 依赖 | 不应替代它的工作 |
|---|---|---|---|
| 1 | 不会卡死、不会错误判定、不会破坏旧档 | 参数和错误契约 | 视觉改版、增加元件 |
| 2 | 可持续保存和恢复的完整项目 | 项目 schema、迁移、事务 | 多存档按钮但仍丢源码 |
| 3 | 不阻塞界面的实验会话 | 独立内核状态、Worker | 仅增加运行速度档位 |
| 4 | 看见信号变化并复现失败 | 轨迹、检查点、实例映射 | 只添加颜色和动画 |
| 5 | 序章和第一个世界真正可玩 | 编辑、保存、反馈链路 | 同时扩充数十个新关卡 |
| 6 | 从门到 CPU 的整体课程与作品 | 可靠 ISA、组件版本、课程契约 | 提前加入 RISC-V、FPGA |

## 5. 可复用与不可直接复用

**直接保留并加固：**现有元件行为、程序化搭建工具、参考电路、31 关 ID、Z16 编码与示例资产、基本 Canvas 渲染。

**需要拆分：**大一统编辑 store、UI 内的仿真对象、与 UI 耦合的本地保存、混合构造函数和内容的关卡数据。

**不在本期引入：**上级工作区的 Agent/后端框架。当前需求没有远程代理或平台账户；共享库若要使用，另行核对依赖基线和未提交修改，本方案不修改其他仓库。
