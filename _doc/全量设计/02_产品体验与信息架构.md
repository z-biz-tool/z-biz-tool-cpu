## 5. 全局运行对象与状态（SIM-01、SIM-02、DBG-02）

### 5.1 对象归属必须可见

| 对象 | 允许动作 | 隔离与标识 |
|---|---|---|
| 我的电路 | 输入、运行、复位、快照；搭建模式编辑设计 | 显示项目、设计版本、根及完整实例路径 |
| 参考机 | 运行自己的源码、观察参考架构 | 常驻“参考 Z16”标识；不授予个人电路通关证据 |
| 测试实例 | 回放题目输入、检查首次失败 | 显示关卡修订、用例、seed、设计版本；不得污染草稿 |
| 历史观察 | 游标查看旧值、定位信号 | 明示“历史，只读”；默认不改变实时实例 |

- 工具栏一次只控制一个已选对象；切换对象先暂停旧对象，新对象默认暂停，不暗中并行运行。
- 切换面板不切换对象、不重装程序、不丢 PC、RAM、终端游标；会话独立于标签组件。
- 用户 CPU 未配置有效调试适配器时显示“未映射”，仍能做电路仿真；不能用参考机数据填空。
- CPU 单步明确区分“微拍”和“指令”；指令单步等到完成事件或预算终止，不假定固定拍数。
- 程序装载属于独立操作：预览诊断与覆盖范围，成功后复位目标运行实例；失败保留旧程序。

### 5.2 运行状态、二态边界与失败语言

| 状态 | 页面表达 | 主操作 |
|---|---|---|
| 未编译／待重新编译 | 显示对应设计版本，不显示可信新输出 | 编译并开始实验 |
| 编译错误 COMPILE_ERROR | 问题列表与冲突网络；数值标为无效或历史 | 定位并修复，禁止运行与通关 |
| 已暂停／运行中 | 当前对象、逻辑时间、速度；等待任务确认后改状态 | 运行／暂停／单步 |
| 正常停机 HALTED | 区分程序主动停机与用户暂停 | 查看最终状态或复位 |
| 不收敛 NON_CONVERGENT | 展示已取得的周期／环路证据 | 回放或修改；无证据不武断称振荡 |
| 资源限制 RESOURCE_LIMIT | 显示命中预算、完成到哪里 | 减少规模、缩短运行或重试 |
| 取消 CANCELLED／运行错误 RUNTIME_ERROR | 取消不是答错；错误附可导出诊断 | 回到草稿或重建运行实例 |

- 本期是二态、零传播延迟、离散事件教学模型；不模拟 X/Z、亚稳态、真实传播延迟。
- 未连接输入兼容为 0，同时显示未驱动警告；是否阻断由关卡契约声明，不让灯亮掩盖缺线。
- 位宽范围 1–32；不兼容的扩展／截断须明确处理。多驱动、非法端口、非法位宽等阻止运行。
- 同沿器件读取同一旧状态；RAM 组合读、沿触发写；采样前值和提交后值在波形中分开解释。
- 旧版本迟到响应不得覆盖新设计；取消、运行进度及错误必须带当前对象与版本归属。

### 5.3 保存状态不是运行状态（PRJ-01）

- 顶部独立显示“未保存／等待保存／保存中／已保存·修订／保存失败／只读副本”，不能用运行成功代替保存成功。
- 设计、汇编、关卡草稿、测试台、探针配置进入项目；运行快照另存并绑定设计哈希、内核与 ISA 版本。
- 自动保存目标为停止编辑 500ms 后提交、连续编辑最长等待 2s；只有本地事务提交后显示“已保存”。
- 保存期间又发生编辑时，只确认已提交修订，新修订仍显示待保存；手动保存要求刷写当前修订。
- 保存失败常驻提示“尚未写入本地”，保留内存草稿，提供重试、导出 JSON、取消离开；不自动清空。
- 切关／新建前等待当前草稿提交，失败时不默认离开；用户可先导出再确认离开。
- 多标签页后打开者只读或另存副本；锁丢失立即停写，展示冲突副本，不静默覆盖。
- 旧数据先原样备份、再幂等迁移且不删除原件；损坏或未知版本保留源文件与错误报告。
- 页面刷新仅承诺恢复已确认保存的数据；退出时的异步保存不是保障，也不承诺自动恢复未经保存的运行态。

## 6. 搭建、实验与引导（EDT-01、EDT-02）

- “搭建／实验”是操作模式；“引导开／关”是正交的信息层，不另造第三份工程。
- 引导按“预测—搭建—观察—解释—迁移”呈现，可跳过、返回、展开完整工具；不会自动替用户改线路。
- 搭建：操作默认选择、移动和连线；实验：操作默认改运行输入，拓扑编辑入口明确标为“暂停并编辑”。
- 输入实验不改设计初值；只有显式“设为初始值”才形成设计事务并触发保存。
- 拓扑／位宽／初值变更先暂停并建立新运行版本；旧轨迹归档为历史，新版本初始运行不继承不兼容状态。
- 平移、缩放、选中与纯布局不影响逻辑时间；布局撤销也不重新编译。
- 两端点击完成连线；预览显示端口方向、位宽及冲突原因，非法目标不提交半条线路。
- 交叉线不自动电气连接；端点连接与交叉用连接点、线型、说明共同表达。
- 放置预览和提交的位置、旋转、镜像一致；数值坐标与“选择元件后点击位置”替代拖动。

### 6.1 撤销和恢复的责任边界

| 动作 | 原子性及撤销结果 |
|---|---|
| 一次拖动／对齐／旋转／镜像 | 仅一条历史；取消拖动恢复原位，无变化不占历史 |
| 参数确认／名称确认 | 输入期间是草稿，确认才提交；非法输入保留可修正内容 |
| 复制粘贴／删除 | 所选元件及内部连线一起处理；删除同步包含相关连线，撤销完整恢复 |
| 封装 | 定义、实例、边界端口和外部线路重映射一次撤销，不留下半成品 |
| 源码编辑 | 文本编辑器独立历史，不撤销画布；装载程序另记一次设计／运行边界操作 |
| 输入切换／时钟推进 | 属于运行事件，不混入设计撤销；用复位、检查点、回放恢复 |
| 新建／切关／查看参考 | 不靠跨项目撤销保命；先保存恢复点，通过项目历史返回 |

- 指针取消、失焦、弹窗中断必须结束或回滚事务；不能把下一次操作并入未闭合拖动。
- 拓扑撤销使关联测试结果标记“旧版本”；历史通过记录保留，不能把旧证据显示成当前草稿已通过。

## 7. 关键场景：正常、异常和空状态

| 场景 | 正常路径 | 异常与空状态 |
|---|---|---|
| 首次进入 | 点亮微实验，预测后操作，结尾保存 | 无本地存储权限：可体验但常驻“临时会话”，提供导出；不伪装持久化 |
| 恢复学习 | 按稳定 ID、修订打开最近草稿 | 无草稿用骨架；旧修订缺资源时给兼容提示，不将新骨架覆盖旧稿 |
| 切换关卡 | 保存 A，再恢复 B，返回时 A 的源码和探针仍在 | A 保存失败则留在 A；用户先导出或明确放弃后才离开 |
| 运行没有变化 | 展示输入、时钟、当前时间，允许单步 | 未驱动时钟指向引脚；正常保持显示“无信号变化”，不显示运行故障 |
| 判题不通过 | 首次失败显示输入／时间、期望／实际、相关接口 | 未完成编译先处理契约错误；无用例是课程包错误，不能算全通过 |
| 点击失败回放 | 一次进入隔离测试实例，波形与画布同一游标 | 缺快照时以原版本和 seed 重跑；版本不匹配则说明无法精确复现 |
| 波形／终端为空 | 波形提示添加探针；终端提示尚无输出 | 采集未启动、程序未到输出、采集超限分别说明；不得虚构历史 |
| 查看参考 | 确认后在应用独立只读视图打开，并保留草稿恢复点 | 资源缺失仍停留原稿；弹窗限制不影响应用内独立视图 |
| 导入工程 | 预览版本、规模、依赖与诊断，再作为新项目打开 | 损坏、未知元件或超限：不替换当前项目，不静默删减 |
| Worker 无响应 | 任务可取消，已保存工程仍可打开 | 2s 内提供终止重建入口；提示运行态可能丢失，不能承诺无损续跑 |

- 回放游标只改变观察；“从这里继续”需确认并从兼容检查点恢复、重放输入，创建新运行分支。
- 轨迹默认预算目标 64MiB，耗尽暂停采集并显著显示覆盖区间；不静默丢旧帧后声称记录完整。
- 无检查点时仅提供只读轨迹或从起点重跑；终端历史使用独立事件序号，不能以截断数组长度充当游标。

## 8. 提示、参考和实例／定义（EDU-02、EDU-03、PRJ-02）

- 提示四级：概念提醒→定位区域→观察建议→局部解法；逐级展开，始终保留“自己继续”入口。
- 完整参考解答不属于第五级提示；二次确认说明“将在独立视图打开，不覆盖草稿”。
- 如需改参考，使用“另存学习副本”；对照视图只提供比较，不提供默认覆盖个人项目的主按钮。
- 使用帮助不扣通关资格，记录自主／辅助／参考后完成；理解勋章依赖新变式证据，而非隐藏答案策略。
- 测试反馈是定位证据，不直接替用户接线；自由文本解释保存为笔记，不做自动语义评分。
- 学习轨遵守固定接口和递归元件约束；自由轨允许探索，作品可复制回课程，但须重新按契约验证。
- “编辑定义”面包屑显示定义名与版本、受影响实例数；没有单一运行值，不把某个实例状态写进定义。
- “观察实例”显示完整路径，例如根／数据通路／ALU-A；同定义 ALU-B 的探针、RAM 和状态相互独立。
- 实例观察默认只读；点击编辑定义先展示影响范围并转入搭建。只改一个实例须派生定义副本并重新绑定。
- 工坊发布组件要求名称、端口方向／位宽／说明、依赖和来源；测试台可附，未验证明确标识。
- 更新已发布定义产生新版本；项目升级前看接口差异、运行测试并可取消，旧版项目可继续打开。

## 9. 快捷键与焦点域（EDT-01）

| 焦点域 | 按键设计 | 不得发生的行为 |
|---|---|---|
| 文本／汇编／参数输入 | Cmd/Ctrl+Z、复制粘贴、方向键归文本；Cmd/Ctrl+Enter 仅在汇编区请求汇编 | 电路撤销、移动、运行或复制副本抢占输入 |
| 画布搭建 | 方向键移动；Cmd/Ctrl+Z 撤销，Shift+同组合重做；删除、复制粘贴处理选区 | 无选中时右方向键不得偷偷单步 |
| 画布局部工具 | R 旋转、W 连线、F 适配、G 封装；设置可关闭或改为修饰键组合 | 单字母快捷键在未聚焦画布时生效 |
| 运行控制／实验画布 | 空格运行／暂停，仅在焦点明确且无文字输入时；单步使用独立按钮 | 空格同时触发按钮与全局监听造成双切换 |
| 元件树／连线表 | 方向键导航，Enter 打开／确认，Tab 离开；连线表选择起点与终点 | 要求先用鼠标命中微小引脚 |
| 波形 | 方向键移动时间游标，Enter 定位信号，Tab 退出 | 波形方向键移动电路元件 |
| 对话框／菜单 | 焦点限制在当前弹层，Esc 关闭并回到触发者 | 穿透弹层删除或修改画布 |

- 焦点分派优先级：弹层→输入法组合输入／文本→当前区域→明确允许的全局命令；先判断再拦截默认行为。
- Esc 每次只退出当前层：取消连线／放置→关闭局部操作→清除选择；运行取消另有可见按钮。
- Cmd/Ctrl+S 在应用焦点内刷写项目；系统保留组合不强占，所有操作都有菜单或按钮等价入口。

## 10. 无障碍与移动边界（AT-12）

- 目标为 [WCAG 2.2 AA](https://www.w3.org/TR/WCAG22/)；实施后逐项核验，不宣称现状合规。
- 文字对比度至少 4.5:1，大号文字至少 3:1；必要图形、控件边界和状态辨识至少 3:1。
- 0/1 同时使用数值、线型和图例；错误用图标＋文字，不仅红绿；支持高对比度和减少动画。
- 常规点击区优先 32–40 CSS 像素；按 2.5.8，最低目标 24×24 CSS 像素，不把 44×44 误列为 AA 必需。
- 小目标例外逐项举证：间距规则、同页等价合规控件、行内链接、未修改的用户代理控件、必要呈现；不能笼统豁免整个画布。
- 间距例外按以小目标边界框中心为圆心、直径 24 CSS 像素的圆核验，不与其他目标或其他小目标对应圆相交。
- 引脚密集时提供合规尺寸连线表及端口选择器；依据同页等价控件例外验收，而不是强行放大后重叠。
- 全流程可键盘完成，无键盘陷阱；拖动均有点击放置、连线表或数值移动替代（2.5.7）。
- 焦点清晰可见，不能被固定工具栏／底栏完全遮挡；定位错误时滚动到元素，关闭弹层恢复焦点。
- Canvas 配套可访问元件树、端口与连接表、当前值和诊断列表；不能仅给整张画布一个替代文本。
- 动态保存／运行／判题摘要使用非打断式状态播报；高速波形不逐变化朗读，用户主动查询当前值。
- 文字放大 200% 不丢内容或操作；320 CSS 像素等效视口下外围界面重排，电路／波形二维区域保留独立滚动和文本替代。
- 悬停内容也可聚焦打开、保持可读、按 Esc 关闭；重要说明不只藏在 tooltip。
- 宽屏使用三栏；窄屏改抽屉和单面板，始终保留运行对象、保存失败和返回入口。
- 手机本期支持课程阅读、作品观察与轨迹查看，不承诺完整复杂搭建；不锁方向，也不自动修改桌面草稿。
- 仅触摸的复杂搭建入口解释限制并建议桌面继续；桌面可访问替代操作不是移动端完整编辑承诺。
