## 1. 技术选择

保留 React、TypeScript、Vite、Ant Design、Zustand、Canvas2D。新增依赖仅为明确需求服务：
- Dexie：IndexedDB 事务、schema 升级和项目仓库。
- Zod：导入、项目、课程和 Worker 协议的运行时校验。
- Vitest、fast-check：单元与性质测试。
- Playwright、axe-core：交互回归、跨浏览器和无障碍检查。

Node 使用 24 LTS；实施 M0 在 CI 核验后锁定具体 Node/npm 补丁版本。保留现有 npm 和锁文件，不为本轮迁移包管理器。版本升级逐项验证，不把未验证的最新依赖作为发布条件。

暂不引入 Monaco、WebGL、WASM、后端框架、CRDT、微服务或多应用 monorepo。现有文本框先完成错误定位、快捷键和源码保存；性能改造首先消除无效重建、整图重绘与主线程仿真。

## 4. 迭代里程碑

假设 2 名前端/交互工程师、1 名仿真工程师、1 名产品/课程人员及共享测试支持。8–10 周是规划估算，须在 M0 基线后重估；不是对实际团队的交付承诺。

| 阶段 | 时间参考 | 交付范围 | 出口门禁 |
|---|---|---|---|
| M0 可信基线 | 第1–2周 | IMP-01/02/03；IMP-04/05关键修复；schema冻结 | 输入与执行类P0关闭；保存风险先隔离，遗留恢复项列为M1阻断；旧样本可解释 |
| M1 可靠实验室 | 第3–4周 | IMP-04分层、IMP-06/07/08 | 所有已知P0关闭；刷新切关不丢已保存成果，取消有效，编辑不误重启 |
| M2 可玩切片 | 第5–6周 | IMP-09/10/11 | 序章＋世界一从引导到失败回放和结算连通 |
| M3 CPU闭环 | 第7–8周 | IMP-05完整验证、IMP-12/13 | 31关逐一通过，CPU多程序差分，组件可复用 |
| M4 打磨验收 | 第9–10周 | IMP-14、内容校对、恢复演练 | 兼容、容量、无障碍和错误恢复均有实测证据 |

关键路径：仿真契约 → Worker会话 → 轨迹/回放 → 课程反馈 → CPU Boss。课程脚本、视觉设计和固定测试夹具可以并行，但不能凭未实现接口制作误导性演示。

只有 1–2 名工程师时，先交 M0＋M1，再交序章和世界一；后续按模块继续。不删恢复、输入限制和正确性测试去凑原工期。

## 5. 渐进迁移策略

1. 引入诊断、预算、schema 时保留旧入口，先使现有功能接受相同校验。
2. 旧 store 调用新的 command/repository facade，逐步迁出责任，避免一次性改所有 UI。
3. Worker 客户端先覆盖复位、单步、输入，完成会话一致性后再覆盖连续运行和判题。
4. 初期保留旧课程资源和已保存进度；新课程以 revision 分流，不覆盖旧尝试。
5. 更换调度与 ISA 行为时使用明确版本，提供副本迁移与结果对比。
6. UI 切换时旧数据不删除。无法向下迁移的工程只读打开并提示适用版本，不由旧应用重写。

兼容目标是保留可恢复数据与明确行为，不是永久维护每个历史漏洞。安全校验和资源边界覆盖所有版本。

## 6. 后续 CI 与发布门禁

未来 CI 顺序为：可复现依赖安装 → typecheck → lint/格式检查 → 单元/性质测试 → 原verify入口 → 课程资源校验 → 构建 → 浏览器回归 → 容量与无障碍报告。

- 浏览器测试使用当前稳定 Chrome 与 Safari 对应环境；Playwright WebKit 作为自动化近似，真实 Safari 另做冒烟验证，不能混称完全等同。
- PR 内展示课程版本/引擎版本变化、迁移影响和测试结果。
- 课程输出由构建器确定性生成，缺参考解答、缺测试、先修环或未知知识点阻止发布。
- 性能比较使用固定夹具、硬件档与浏览器版本；一次偶然快跑不能证明 p95 达标。
- 无后端部署仍需 HTTPS、安全响应头和正确资源缓存；本期不缓存敏感账户信息，因为本期没有账户体系。

发布保留旧静态版本入口及课程 manifest。回滚应用不回滚用户数据；新版格式不能由旧版自动重写。正式部署和 Git 操作需另行授权，本次文档交付不执行。

## 7. 何时重新评估技术路线

| 触发条件 | 可考虑措施 | 不提前做 |
|---|---|---|
| 大图命中/绘制仍不达标 | 更细空间索引、图层缓存，再评估WebGL | 全量重写编辑器 |
| 仿真计算成为已测瓶颈 | 编译缓存、TypedArray、专用求值器，再评估WASM | 把主线程问题误当语言问题 |
| 课程需X/Z或冒险实验 | 新语义版本、真值表、迁移课程 | 默默改变旧关答案 |
| 用户明确需要跨设备/班级 | 独立在线平台设计与权限/信任边界 | 给本地成绩加登录就称考试 |
| 内容量增大且发布频繁 | 内容管理工具与资源签名评估 | 第一版自建完整CMS和市场 |
