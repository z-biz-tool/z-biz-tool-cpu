# 09 · 产品课程全景：从二态门到设备之书

> 状态：规划（按 cpu_work/memory_work / mini_machine 三套笔记与 08 草案的实施顺序）
> 落地基线：CPU 书 31 关 + 存储书 18 关全上架；机制 6 介质元件；5/4 处既有失败与本书无关
> 留档：物理/化学世界（二极管层以下），暂不动

## 0. 一句话定位

**让一根被二进制编译成一个物理系统，从二态门一路走到能跑 OS 的整机 + 设备家族。**

四本书的连贯叙事：

```
物理（留档） → 数字电路（CPU 书，已交） → CPU 优化（优化书，规划）
                               ↓
              存储书（已交） ─── 编程与烧录（程序书，规划）
                               ↓
              整机骨架（mini_machine 书，规划）→ OS（OS 书，规划）
                               ↓
              设备家族（显示/键盘/网络…，规划）
```

## 2. 第一本：优化书《流水线与之后的一切》（book-fast）

**母本：** `z-how-linux-runs/cpu_work/06-为了快-流水线与之后的一切.md`
**核心观点：** 快的每一分钱都花在重组现有零件上，不引入新能力。

### 关序列（草拟 14 关 / 4 世界）

| 世界 | 关 | 名称 | 玩法骨架 | 判据形态 |
|---|---|---|---|---|
| **F1 切长路径** | F1-1 | 单周期 ALU 长在哪 | 给一段单周期 Z16 数据通路，测关键路径总延迟；让玩家用逻辑分析仪点出最慢一段 | 信号延迟断言（最慢段数） |
| | F1-2 | 一拍分成五拍 | 在数据通路五站之间插寄存器；同一程序现在五拍完成一条指令 | `outputs: sequence 数/端`，预算 5 拍 |
| | F1-3 | 数据冒险的眼泪 | 在 RAW 依赖相邻两指令间插入 `nop`；验证依赖跨拍传递 | 寄存器输出序列校验 |
| | F1-4 | 转发旁路 vs 插气泡 | 让玩家在 EX→EX 与 MEM→EX 两个转发点选一条；不同程序胜出不同 | `outputs` 比对，预算成本 |
| **F2 控制冒险** | F2-1 | 分支的代价 | 测 beq 走后下一拍 PC 已经在变 → 错取指 | 错取指一拍纠正 vs 不纠正的 PC 序列 |
| | F2-2 | 静态预测：总是跳 | 测一个总是跳的循环，看 PC 错取率 | `outputs: PC 错拍数` |
| | F2-3 | 动态预测：2-bit 饱和 | 给玩家一个 4 状态格；测预测准确率 vs 静态 | 累计 mispred over 程序 |
| | F2-4 | BTB 与目标缓存 | 实测查表预测 vs 总是跳；统计节省拍数 | mispred 数 = 0（特定程序） |
| **F3 缓存层级** | F3-1 | 为什么加 L1 | 给一段循环，测纯 RAM 取指的拍数；插 L1 后骤降 | `outputs` 取指拍数 |
| | F3-2 | 直接映射与冲突 | 两段程序访问同一路不同 tag → 冲突；实测 miss 率 | miss 计数断言 |
| | F3-3 | 组相联与替换 | 2 路组相联 vs 直接映射；同样冲突模式下前者胜 | 性能对比 |
| | F3-4 | 写策略：写回 vs 写穿 | 让玩家选一种，验证一致性差异 | mem 状态 vs 性能 |
| **F4 拆墙与多核** | F4-1 | Dennard 失效：频率卡死 | 在固定功耗预算下，单核提频收益递减；改双核 | `outputs: 时间@CPU` |
| | F4-2 | Amdahl 定律：并行天花板 | 给一段 80% 可并行 + 20% 串行的程序；测双核加速比 | 加速比断言 |
| | F4-3 | MESI 一致性四态 | 两核改同一行，测 M/M/E/S 状态机 | mem 检查 + 状态序列 |

**实现要点：**
- 元件：新增 `PIPEREG`（流水线寄存器：`if/id`、`id/ex`、`ex/mem`、`mem/wb`）、`BRANCH_PRED`（含 BTB 表）、`CACHE`（含 tag/data 双口）、`MESICOHE`（四态状态机）。与存储书元件同构落 `registry.ts`。
- 测试：性能断言 = `outputs: 累计拍数` 或 mem 校验 + 行为断言组合；不引入新判据类型。
- 反哺：关底产物 = 流水化 Z16，可作为存储书 m4-x 的"快存"用作启动加速。

## 3. 第二本：程序书《从代码到跑起来》（book-program）

**母本：** `z-how-linux-runs/01a-从代码到跑起来-完整链条.md`
**核心观点：** 不只写代码，看代码怎么变成 CPU 跑得动的字节。

### 关序列（草拟 12 关 / 3 世界）

| 世界 | 关 | 名称 | 玩法骨架 | 判据形态 |
|---|---|---|---|---|
| **P1 编码与链接** | P1-1 | ASCII 把图发到文件 | 输入一段汇编；按字符展开为字节；观察字面值与小端序 | mem 字节序断言 |
| | P1-2 | 指令编码 | 把 `addi r1,r2,5` 编成 16 位机器码；手算字段 | mem 比较与字段切片 |
| | P1-3 | 符号表与重定位 | 两文件各引对方的符号；展示 link 前后的地址差 | 链接前后 mem 对照 |
| **P2 装载与点火** | P2-1 | MBR 的 512 字节 | 把 512 字节装载到 `0x7C00`，验证 BIOS 的实模式惯例 | mem@0x7C00 字节序断言 |
| | P2-2 | 无仪式点火 | 从 `0x7C00` 起跳；CPU 执行第一条指令；PC 序列正确 | PC 序列断言 |
| | P2-3 | `.data / .bss / main` 启动三件事 | 测 ELF 装载后的内存布局 | mem 各段断言 |
| **P3 烧录与观测** | P3-1 | 烧到 ROM | 把机器码写进 ROM，掉电后从 ROM 起跳 | mem@0 掉电前后断言 |
| | P3-2 | 串口 echo | 写 UART 驱动；按键字符从串口回到终端 | log 序列断言 |
| | P3-3 | 看门狗 | 启用 WDT，循环空转 → 复位 | 复位次数断言 |
| | P3-4 | printf 不带 libc | 自己实现最小 printf：用 UART 与寄存器栈 | log 输出与基准对比 |
| | P3-5 | 中断驱动按键 | 不再轮询；用 NVIC 路由按键中断 | 14 拍 vs 0 拍响应断言 |
| | P3-6 | DMA 解放 CPU | 用 DMA 搬一块数据；CPU 同步等待 | 拍数差异断言 |

**实现要点：**
- 元件：复用 CPU + 存储书的全部；新增 `ROM`（rom 已存在）、`UART`、`NVIC`（中断控制器）、`WDT`、`DMA`。
- 判据：log 序列 + mem 字节序 + 拍数预算。
- 反哺：程序书 P3 系列 = mini_machine 书的"用户程序"教学切片。

## 4. 第三本：mini_machine 书《把零件焊成一台机器》（book-machine）

**母本：** `z-how-linux-runs/mini_machine/00-05`
**核心观点：** 零件躺桌上不等于机器；总线/时钟/复位/外设是 CPU 与内存之间的焊肉。

### 关序列（草拟 15 关 / 4 世界）

| 世界 | 关 | 名称 | 玩法骨架 | 判据形态 |
|---|---|---|---|---|---|
| **M0 蓝图** | M0-1 | 最小系统七件套 | 给一块画板，让玩家在固定空间内放置：CPU/SRAM/Flash/总线桥/晶振/复位/电源 | 结构断言 + 元件白名单 |
| | M0-2 | 地址地图 | 验证 Flash@0、SRAM@0x2000、外设@0x4000 的统一映射 | mem 寻址断言 |
| **M1 总线** | M1-1 | 一根数据线三种 | 三态门分时共享数据线；CS/OE 控制 | 信号冲突 → 多驱动阻断（应已存在） |
| | M1-2 | AHB 与 APB 分家 | 高速 CPU ↔ 总线 ↔ 低速外设；桥接一拍代价 | `outputs: 拍数` |
| | M1-3 | 等待周期 | 让外设慢一拍 ready；CPU 插入等待 | PC 停顿拍数 |
| **M2 时钟与复位** | M2-1 | 时钟树 skew | 给时钟线加长；同一拍不同寄存器的边沿错位 | 时序断言（沿错位 1 拍） |
| | M2-2 | 复位取向量 | 上电后 PC = reset vector；执行 startup | PC 序列断言 |
| | M2-3 | POR 与 BOD | 模拟掉电；复位后再上电 → 重新启动 | mem@PC 序列重启 |
| **M3 外设与中断** | M3-1 | GPIO 推挽 | LED = 1 时输出高；读输入时施密特防抖 | 输出值序列 |
| | M3-2 | UART 波特率 | 测 115200 8N1 的位时间；发一个字节 | log 序列 |
| | M3-3 | Timer PWM | 给一个 PWM 占空比；测方波周期与高电平拍数 | 波形断言 |
| | M3-4 | NVIC 中断路由 | GPIO 边沿 → 中断号 → 跳到 ISR | 中断服务拍数 |
| | M3-5 | DMA 通道 | 用 DMA 搬 1KB；CPU 同时跑别的程序 | mem 终态 + 拍数对比 |
| **M4 整合与裸机** | M4-1 | 通电一秒全流程 | 从上电到串口输出第一行 prompt；PC 序列对 | 完整 PC 序列 + log |
| | M4-2 | 60 行裸机程序 | 实现 mini_machine/05 的最终程序；可继续 | log 序列 + 项目持久化 |
| | M4-3 | 长大后必然长出 OS | 多个任务 → 协作切换 → 抢占 → 系统调用 | PC 跳转表 + 拍数限制 |

**实现要点：**
- 元件：`AHB`、`APB`、`PLL`、`WATCHDOG`、`BOD`、`NVIC`、`DMA`、`GPIO`、`UART`、`TIMER`（多个）。复用 CPU + 存储全部元件。
- 测试：波形 + PC 序列 + log；新增 `waveformCheck` 判据（多通道在指定 tick 的值）。
- 反哺：mini_machine OS 的程序 = 程序书 P3 系列的运行环境。

## 6. 设备家族（book-devices）

存储书是第一本设备书（`book-memory`）。设备 = 状态机 + 寄存器面板 + 中断/DMA 路径。

**可衍生的设备书模板（每本 8-12 关）：**

| 设备 | 锚定笔记 | 核心元件 | 关序列骨架 |
|---|---|---|---|
| 显示 📺 | — | `VGA_TIMING`、`VRAM`、`DAC` | 同步信号 → 扫描线 → 字符模式 → 像素 → 帧缓冲 → 双缓冲 |
| 键盘 ⌨️ | — | `KEYBOARD_SCAN`、`PS2` | 扫描码 → 字符映射 → 缓冲 → 中断 → 重复按键 |
| 网络 🌐 | — | `NIC`、`MAC`、`PHY` | 帧封装 → CRC → 缓冲环 → 中断 → 协议栈骨架 |
| 音频 🔊 | — | `PCM`、`I2S`、`DAC` | 采样率 → 缓冲 → 双缓冲 → 混音 → PWM 输出 |
| 传感器 🌡️ | — | `ADC`、`I2C`、`SPI` | 模拟输入 → 采样 → 校准 → 中断 → 上报 |
| 磁盘控制器 💾 | 存储书深化 | `IDE`、`SATA`、`NCQ` | 队列 → 寻道命令 → 中断 → 多队列 |

每本设备书都走存储书的"物理=预算"路线，把外设的真实时间/带宽/排队翻译成拍数与配额。
