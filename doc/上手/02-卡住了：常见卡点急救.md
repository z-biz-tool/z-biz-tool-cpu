# 卡住了：常见卡点急救

> 按**症状**查，不要按概念查。
> 每条都是「现象 → 真因 → 怎么做」。带引号的句子是界面/诊断里真实出现的文案。

---

## A. 电路不工作

### 1. 灯一直是 0，元件好像没通电
**真因**：多数是线没接。交叉的两根线在画布上**不会**自动相连。
**怎么做**：看诊断里有没有 `输入未连接，按 0 读取（未驱动）：...`。有的话，按名字找到那个引脚，把它接上。
要固定电平就放一个「常量」元件，别指望悬空等于 1。

### 2. `多个输出接到同一根导线：...`
**真因**：两个以上元件的**输出**接到了同一个网络上（画布上允许画，电气上不允许）。
**怎么做**：这类冲突只能用选择器（MUX）解决，不能靠"两根线接一起"。想合并就让其中一个走 MUX，由控制信号决定谁上总线。

### 3. `定宽引脚接在更宽的总线上，将按低位截断`
**真因**：把 8 位总线接到一个 1 位或 4 位宽固定的引脚上了。低位保留，高位丢掉。
**怎么做**：先缩小（分线器取需要的位），或者换成参数化位宽的元件。别把这条当警告忽略——截断是最常见的"结果莫名其妙"来源。

### 4. `时序元件没有时钟，不会动作`
**真因**：触发器的 clk 脚没接。
**怎么做**：接一个「时钟源」（自动打拍），或者接一个手动的 input 当 CLK（自己拨 0→1 就是打一个上升沿）。
注意：**时钟源每 divide 拍给一次上升沿**，divide=1 就是每拍一次。

### 5. 判题说「全部通过」，但画面一动不动
**真因**：仿真没在跑。判题是在内部跑一遍用例，不是把画面推起来。
**怎么做**：按 <kbd>空格</kbd> 运行，或 <kbd>→</kbd> 单拍。要看中间值就打开「探针」面板。

### 6. 一按运行就报「振荡 / NON_CONVERGENT」
**真因**：存在组合环（输出经组合逻辑绕回自己的输入），而且这个环不收敛。
**怎么做**：组合环只有一种合法用法——**锁存器**（交叉耦合的与非门）。如果环里没有"记忆"的意图，就是接错了：找出绕回去的那根线，改走触发器。

### 7. 我改了 D，Q 没变
**真因**：D 触发器**只在时钟上升沿采样**，电平变化期间 Q 保持。
**怎么做**：先让 D 稳定，再给一次 0→1。序章第三关就是专门练这个的。

## B. 判题不给过

### 8. 「以下元件不在关卡允许列表内：...」
**真因**：这一关有白名单（例如门级题不许直接用加法器）。
**怎么做**：换成允许的元件自己搭。白名单是关卡设计的一部分，不是 bug。

### 9. 「输出位宽 8 小于契约 4 位，禁止缩小比较域」
（真实文案形如 `输出位宽 N 小于契约 M 位`）
**真因**：你把输出元件的位宽改小了，想用截断"凑"过比较。
**怎么做**：改回骨架给的位宽。判题按骨架契约比，改小不算通过。

### 10. 用例里明明对了，但整体不通过
**真因**：判题是**全部用例都过**才算过。往下翻，通常还有一条 ✗。
另外「诊断」里的 error 级（多驱动、找不到子电路）也会直接判不通过，即使用例全过。

### 11. 这关过不去，下一关点不动 / 标「先修 N」
**真因**：关卡有先修关系。
**怎么做**：点它会弹窗，给出「最短补充路径」。也可以直接进入——判题、勋章都照给，只是前面那几关的记录不会补上。

## C. 子电路 / 工坊

### 12. 打包之后，工坊里标「待完善元数据」
**真因**：组件缺名称、说明或端口说明（旧档导入的、当时跳过说明的都会这样）。
**怎么做**：工坊列表里点「补全说明」。**不补也能用**，只是别人（以及三个月后的你）看不懂端口。

### 13. 工坊里点「放入画布」没反应
**真因**：当前画布正在看这枚组件自己的子电路——不能把自己塞进自己。
**怎么做**：切回主电路（画布左上角的面包屑 / 属性面板的视图切换）再放。

### 14. `找不到子电路定义 xxx` / `子电路 "xxx" 存在循环引用`
**真因**：设计里引用了 `custom:xxx`，但 defs 里没有这个定义；或者子电路互相包含。
**怎么做**：从工坊重新「放入画布」——它会连带把依赖的子电路一起补进来。循环引用只能手工拆：把其中一层改成直接搭。

### 15. 升级组件后，旧项目打不开 / 接线乱了
**真因**：组件版本不可变，升级是**新版本**；旧项目仍然引用旧版。接口变了就会错位。
**怎么做**：工坊里点「查看升级」看接口差异（新增/删除/位宽变化）。有删除或位宽变化的话，先在新画布试，再决定是否迁移。

## D. 案例库（100 个）

### 16. 案例怎么变成我自己的电路
**做法**：案例库 →「放入画布」。它会作为子电路进入当前设计，同时在工坊里留一份索引。
想改：放到画布后,双击/在属性面板里进它的子电路视图改（改的是当前设计里这一份，不会污染案例库）。
想要独立文件：工坊「导出备份」得到 `workshop.json`。

### 17. 案例放进去，报「找不到子电路定义」
**真因**：老版本遗留（依赖闭包还没做的时候放的）。
**怎么做**：把那个组件从画布删掉，重新从案例库「放入画布」——现在会把依赖一起带进来。

### 18. 「在本机重跑自检」出红
**真因**：要么是浏览器环境问题，要么是真 bug。
**怎么做**：终端里跑 `npm run verify:gallery`（这是权威口径，100/100 才算过）。
如果终端绿、浏览器红，把控制台报错贴出来——那是环境差异，不是案例坏了。

## E. 数据 / 存档

### 19. 另一个标签页改过草稿，提示冲突
**真因**：草稿位有写锁，两个标签页同时编辑会打架。
**怎么做**：冲突副本会进项目库（书架「项目库」），两份都在，自己挑一份保留。

### 20. 载入参考解之后想回到自己原来那版
**做法**：<kbd>⌘Z</kbd> 撤销；或者书架「项目库 → 项目历史」里回到替换前那一份（整盘替换前自动留底）。

### 21. 我好像把设计搞丢了
**做法**：先看书架「项目库」——关卡半成品、存档位、冲突副本、项目历史都在那里列着，每条都能直接回去。
这些都在本地存储里：清浏览数据/换机器就没了，重要作品请「导出」。

## F. 还是不行

1. 手册面板（右侧最后一个标签）里有快捷键、Z16 指令集、诊断含义。
2. 跑一遍 `npm run verify` 和 `npm run verify:gallery`，确认不是环境问题。
3. 提 issue 时请带上：关卡 id（或案例 id）、你接的线、判题里那句具体文案。**带文案的问题几乎都能一次定位**。
