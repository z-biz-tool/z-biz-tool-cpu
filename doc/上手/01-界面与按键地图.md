# 界面与按键地图

> 这一页回答「这个按钮是干什么的」。看一遍，之后只在卡住时回来查。

---

## 一、书架页（`/`）

| 区域 | 作用 |
|---|---|
| 三张书卡 | **CPU 书**（31 关，从门到 Z16）、**存储书**（18 关，DRAM/Flash/磁盘）、**优化书**（8 关，流水线与冒险）。点卡片就进这本书 |
| 总进度圆环 | 三本书合计通过关数 |
| ✦ 上手引导 | 五步引导，第一次进来自动弹；之后随时可以从这里打开 |
| 项目库 | 你本地真有的可回条目：关卡半成品、存档位、冲突副本、项目历史。**不是装饰**——整盘替换前都会自动留底 |
| 底部沙盒入口 | 没有关卡在手时直接进自由搭建 |

## 二、编辑器（`/lesson` 与 `/sandbox`）

URL 就是意图：`/lesson` 带判题上下文，`/sandbox` 只搭不判。切换时画布**一个元件都不动**。

### 顶部工具栏

| 控件 | 作用 |
|---|---|
| 返回书架 | 回 `/` |
| 撤销 / 重做 | 与 <kbd>⌘Z</kbd> / <kbd>⌘⇧Z</kbd> 同一套栈 |
| 工具：选择 / 连线 | 或按 <kbd>W</kbd> 切换 |
| 运行 / 暂停 / 单拍 | 空格、→ |
| 适应视图 | <kbd>F</kbd> |
| 缩放 | 0.25×–3×（<kbd>⌘</kbd>+滚轮也行） |
| 新建 / 打开 / 保存 / 存档 | 「存档」是一个可覆盖的存档位；整盘替换前会自动进项目历史 |
| 导入 / 导出 | 纯 JSON 的设计文件，可分享、可进 git |
| 打包子电路 | 等价于选中后按 <kbd>G</kbd> |

### 左侧：元件库

按类别分区：输入输出 / 逻辑门 / 运算 / 选择器 / 总线 / 时序 / 存储 / 辅助。

- 点一下 = 放到画布中央；也可以直接拖。
- **灰色 = 这一关不允许用**（关卡有白名单，防止用现成 ALU 去解门级题）。
- 门 / 选择器 / 分线器的**参数**在右侧属性面板里改（输入数、位宽），改完外形会跟着变。

### 中间：画布

- 线有颜色，代表电平高低；悬停引脚会显示位宽。
- 交叉的两根线**不会**自动相连（没有"节点"概念），要连就得真的连到引脚。
- 未连接的引脚会标「未驱动」，时序元件的时钟没接会在判题时单独提示。
- 选中多个元件后按 <kbd>G</kbd> 打包成子电路，它会同时登记进工坊。

### 右侧：面板（九个标签）

| 面板 | 什么时候用 |
|---|---|
| **关卡** | 读任务/讲解、切书、运行测试、看参考解。默认停在这里 |
| **属性** | 选中元件后改参数（位宽、输入数、初值、ROM 内容…）；也是唯一能改「命名」的地方——**命名后才会出现在探针和波形里** |
| **汇编** | 给参考 Z16 写程序，实时汇编，可直接装载进 RAM |
| **CPU** | 参考 CPU 的寄存器、标志、反汇编视图 |
| **工坊** | 你的封装组件 + **100 个案例库**；版本不可变，升级先看接口差异 |
| **探针** | 所有已命名元件的当前值 |
| **日志** | 运行日志（含「终端输出」元件打印的内容） |
| **手册** | 上手三步、快捷键、Z16 指令集、诊断含义 |

## 三、判题结果怎么读

点「运行测试」后，结果按这个顺序读：

```
全部通过 / 还没通过        9/9 · 花费 12
  ↑ 通过数   ↑ 元件成本（基准 8 = 参考解的规模，只作参考）
```

然后是每个用例：

```
✓ 用例 1:  A=1 B=0        ← 用例名（关卡作者起的名字）
   ✓ 输出 Y  期望 0x01 (1)，实际 0x01 (1)
   ✗ 输出 Z  期望 0x00 (0)，实际 0x01 (1)
```

- **期望 vs 实际**是逐值对比，不是"整体对/错"，所以能直接看出是哪一位不对。
- 位宽也在一起比：输出位宽小于骨架契约会直接判失败（防止偷偷缩小比较范围）。
- 最后是**诊断**（多驱动、未驱动、位宽截断、时钟没接）。这些是布线体检，不是判题结论。

## 四、快捷键

| 键 | 作用 |
|---|---|
| <kbd>空格</kbd> | 运行 / 暂停 |
| <kbd>→</kbd> | 单拍（有选中元件时改为右移 1 格） |
| <kbd>←</kbd> <kbd>↑</kbd> <kbd>↓</kbd> | 移动选中元件 |
| <kbd>⌘Z</kbd> / <kbd>⌘⇧Z</kbd> | 撤销 / 重做 |
| <kbd>Delete</kbd> | 删除选区 |
| <kbd>R</kbd> | 旋转选中元件（放置中也能转） |
| <kbd>W</kbd> | 连线工具开关 |
| <kbd>G</kbd> | 把多选元件打包成子电路 |
| <kbd>F</kbd> | 适应视图 |
| <kbd>⌘D</kbd> | 复制选中元件 |
| <kbd>Esc</kbd> | 取消放置 / 取消连线 / 清空选区 |
| <kbd>I</kbd> | 跳到属性面板 |

**什么时候不生效**：焦点在输入框、下拉框、弹窗里；或焦点在「可访问视图」（元件清单 / 连接表 / 波形）里——
那三块自己用方向键走位、空格是"选中这一行"，不是"运行"。这是刻意的：一个按键只属于当前焦点域。

## 五、可访问视图（键盘 / 读屏）

画布是位图，读屏拿不到形状，所以另有一份等效清单（用 <kbd>Tab</kbd> 移到画布右侧会显形）：

- **元件与端口**：每行一个按钮，方向键走访、回车选中，画布和属性面板跟着同步。
- **连接表**：列出每根线的两端；可「断开这根线」或「从 X 改接」。
- **未连接端口**：按两次（起点 → 终点）就能在键盘上完成一根连线，不用去点几像素大的引脚。
- **诊断**：与判题结果里的诊断同源。

保存、运行、判题结论会以不打断的方式播报；波形不逐拍朗读，需要的话用「读取当前引脚值」。

## 六、你的东西存在哪

| 东西 | 位置 | 备注 |
|---|---|---|
| 草稿（画布这一份） | 本地存储，自动保存 | 换标签页也不会丢 |
| 关卡半成品 | 每关一个存档位 | 离开关卡时自动存 |
| 存档位 | 一个，可覆盖 | 工具栏「存档」写、书架「项目库」读 |
| 项目历史 | 最多 20 份 | 整盘替换前自动留底，可回退 |
| 工坊组件 | 本地存储 | 可导出 `workshop.json` 备份 |
| 通关进度 / 成就 | 本地存储 | 仅作自学记录，不是可信认证 |

> 这些都是本地的：换机器要自己带 `workshop.json` 和导出的设计文件。
