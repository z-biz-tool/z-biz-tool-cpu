# 15 分钟上手

> 目标：这 15 分钟结束时，你已经**通过 3 个序章关**，并且知道卡住时该按哪个按钮。
> 不需要任何预备知识——不认识「与非门」「上升沿」都没关系，序章会讲。

---

## 一分钟版本

1. 打开应用 → 书架页选 **CPU 书**。
2. 点第一关 **序章·点亮信号灯** → 右侧读「任务」和「讲解」。
3. 从左侧元件库拖元件到画布，按 <kbd>W</kbd> 连线，按 <kbd>空格</kbd> 运行，点「运行测试」看结果。

三句话讲完的操作，就是这套工具的全部交互。剩下的都是这条线的变体。

---

## 0. 打开应用

**已经装了发行包**：直接双击打开。

**从源码跑**：

```bash
cd z-biz-tool-cpu
npm install
npm run dev        # 浏览器里打开（开发用）
npm run tauri dev  # 桌面窗口（需要 Rust 工具链）
```

跑自检（确认这台的运行环境是好的）：

```bash
npm run verify            # 内核 + 57 关参考解 + 参考 CPU
npm run verify:gallery    # 100 个工坊案例
```

## 1. 序章三关（约 10 分钟）

书架页 → CPU 书 → 第一层的上面三关，标着「序章」。

| 关卡 | 你要做的事 | 学到的概念 |
|---|---|---|
| **点亮信号灯** | 画布里已经接好一根线：开关 S → 灯 L。跑起来，把 S 切到 1 | 组合电路没有记忆：输入变，输出立刻变 |
| **修好断开的信号线** | S 已经是 1，但灯不亮。把 S 的输出接到 L 的输入 | 「灯不亮」通常是线没接，不是元件坏了 |
| **记忆门只在约定时刻收件** | 把 D 接到触发器的 d 脚；先 D=1 但 CLK=0，观察 Q 不变；再打一个上升沿 | 时序元件只在时钟沿采样，平时保持旧值 |

这三关没有陷阱，专门用来练手感：**拖动、连线、运行、判题**。

> 判题不通过不会锁住你。它会告诉你哪一条测试没过、期望值是多少、实际是多少——
> 那句话通常就是答案。

---

## 2. 四个动作

### 拖
左侧元件库 → 点一下（放到画布中央）或直接拖进画布。灰掉的元件是这一关不让用的。

### 连
按 <kbd>W</kbd> 切到连线工具 → 点一个**输出引脚**再点一个**输入引脚**。
错了按 <kbd>Esc</kbd>，整根线按 <kbd>Delete</kbd>。

### 跑
<kbd>空格</kbd> 运行/暂停，<kbd>→</kbd> 单拍推进。
组合电路一接就生效；时序电路要打拍才动。

### 判
右侧关卡面板 →「运行测试」。结果分三块：

- **通过 / 没通过** + 花费（元件成本，越少越好但不是必须）
- **每条用例**：✓/✗ + 期望值 vs 实际值
- **诊断**：多驱动、未驱动、位宽截断、时钟没接…… 这些不是"报错"，是布线的体检报告

## 3. 卡住了：三个出口（按顺序用）

1. **提示**：关卡面板里鼠标悬停「提示」。一句话点出这一关的关键动作，不给答案。
2. **看参考解**：点「看参考解」→ 官方解答直接载进画布，<kbd>⌘Z</kbd> 可退回。
   载入后关卡会标「看过答案」——判题照旧、勋章照拿，只是不假装是自己做出来的。
3. **工坊案例库**：右侧「工坊」→「打开案例库」。**100 个现成电路**，每个都写了「为什么值得看」，
   可以一键放进画布拆开看。找与你这一关同类的（比如全加器、比较器、状态机）比看答案更有用。

第四个出口是**手册**面板：快捷键、Z16 指令集、诊断含义都在里面。

## 4. 15 分钟之后，往哪走

三条路线，按你想要的收获选：

**想搞懂 CPU 到底怎么跑程序**
→ 走完第一层（与非门 → 异或 → 二选一 → 半加器 → 全加器），
  然后跳到第四层「造一台 CPU」。中间卡住时用汇编面板给参考 Z16 写程序，看寄存器怎么变。

**想搞懂内存/SSD 为什么会坏、会慢**
→ 换到 **存储书《囚禁电荷》**。它用同一个沙盒模拟电容漏电、浮栅寿命、磁盘寻道——
  18 关把「物理」翻译成「拍数」。

**想搞懂为什么 CPU 不能更快**
→ **优化书《流水线与之后的一切》**，8 关。先走完 CPU 书第四层再来。

**想先玩起来**
→ 书架页底部「直接进自由搭建沙盒」，没有判题，随便接。
  或者去工坊案例库，把「迷你 CPU」放进画布按空格，看它自己跑完 1+2+3 然后停机。

## 5. 名词速查

| 词 | 一句话 |
|---|---|
| **组合电路** | 输出只看当前输入，没有记忆。与门、加法器、选择器都是 |
| **时序电路** | 有记忆，只在时钟上升沿更新。触发器、寄存器、计数器都是 |
| **上升沿** | 信号从 0 变 1 的那一瞬间。时序元件在这时候「收件」 |
| **位宽** | 一根线同时传几个 bit。8 位总线画成一根粗线，接错会截断 |
| **未驱动** | 引脚没接东西，按 0 读。界面会标出来——它比报错更早告诉你哪根线漏了 |
| **子电路** | 选中几个元件按 <kbd>G</kbd> 打包成一个新元件，可以反复用（并进工坊） |
| **参考解** | 官方的标准答案电路，载入后可对照、可拆解 |
