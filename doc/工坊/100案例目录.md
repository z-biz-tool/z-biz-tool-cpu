### 半加器

最小的一次「算术 = 逻辑」。全加器、加法器、ALU、整台 CPU 的进位链，都从这里开始。

端口：`a` 加数 A（1 位）；`b` 加数 B（1 位）；`sum` 本位和：两数不同为 1；`cout` 进位：两数同为 1 时进 1

```
in a 1
      in b 1
      out sum 1
      out cout 1
      x = xor a b
      c = and a b
      sum <- x
      cout <- c
```

### 全加器

只有全加器可以串联——把 N 个全加器的 cout 接进下一个 cin，就是 N 位加法器。这是「位宽」第一次变成可以复制的结构。

端口：`a` 被加数 A；`b` 加数 B；`ci` 低位送来的进位；`sum` 本位和；`cout` 向高位的进位

```
in a 1
      in b 1
      in ci 1
      out sum 1
      out cout 1
      x1 = xor a b
      x2 = xor x1 ci
      a1 = and a b
      a2 = and x1 ci
      o1 = or a1 a2
      sum <- x2
      cout <- o1
```

### 用与非门搭非门

万能门的第一次证明：只要有 NAND，你不需要任何别的门。芯片厂喜欢这句话，因为它意味着只需刻一种晶体管连接方式。

端口：`a` 输入；`y` 取反后的输出

```
in a 1
      out y 1
      g = nand a a
      y <- g
```

### 门级二选一

选择是 CPU 里出现最多的动作（写哪个寄存器、下一条指令在哪）。看清楚「选择 = 两个与门 + 一个或门」，后面看数据通路就不会发怵。

端口：`sel` 选择端：0 选 a，1 选 b；`a` 0 路数据；`b` 1 路数据；`y` 选中的那一路

```
in sel 1
      in a 1
      in b 1
      out y 1
      ns = not sel
      na = and a ns
      nb = and b sel
      o = or na nb
      y <- o
```

### 门级四选一

这是「选择树」的雏形。8 选 1、32 选 1 的寄存器堆读取，都是这棵树继续长高。

端口：`s0` 选择端低位；`s1` 选择端高位（s1s0 = 00→d0 … 11→d3）；`d0` 第 0 路；`d1` 第 1 路；`d2` 第 2 路；`d3` 第 3 路；`y` 选中的一路

```
in s0 1
      in s1 1
      in d0 1
      in d1 1
      in d2 1
      in d3 1
      out y 1
      n0 = not s0
      a0 = and d0 n0
      a1 = and d1 s0
      m01 = or a0 a1
      a2 = and d2 n0
      a3 = and d3 s0
      m23 = or a2 a3
      n1 = not s1
      b0 = and m01 n1
      b1 = and m23 s1
      o = or b0 b1
      y <- o
```

### 三取二表决器

冗余计算的入门题：同一条指令算三遍，取多数，就能屏蔽一次瞬时故障。航天器上的三模冗余就是这个电路乘以几万。

端口：`a` 表决人 A；`b` 表决人 B；`c` 表决人 C；`y` 多数结果

```
in a 1
      in b 1
      in c 1
      out y 1
      ab = and a b
      bc = and b c
      ac = and a c
      o1 = or ab bc
      o2 = or o1 ac
      y <- o2
```

### 8 位奇偶校验位

最便宜的错误检测。串口、内存 ECC、RAID 都从这里起步——代价只有 1 位，换来「一位翻转能被发现」。

端口：`a` 被校验的 8 位字；`p` 奇偶位：a 中 1 的个数为奇数则 1

```
in a 8
      out p 1
      s = split a width=8
      x1 = xor s.b0 s.b1
      x2 = xor x1 s.b2
      x3 = xor x2 s.b3
      x4 = xor x3 s.b4
      x5 = xor x4 s.b5
      x6 = xor x5 s.b6
      x7 = xor x6 s.b7
      p <- x7
```

### 一位相等比较器

相等判断是最基础的分支条件。CPU 的 beq 指令、字符串比较、缓存标签比对，第一块砖都是它。

端口：`a` A；`b` B；`eq` a 与 b 相等时为 1

```
in a 1
      in b 1
      out eq 1
      x = xnor a b
      eq <- x
```

### 两位比较器（门级）

比较器不是「一个元件」，而是一条优先级判断链。看清楚高位优先这件事，你就能自己写出 8 位、32 位版本。

端口：`a1` A 的高位；`a0` A 的低位；`b1` B 的高位；`b0` B 的低位；`lt` A < B；`eq` A = B；`gt` A > B

```
in a1 1
      in a0 1
      in b1 1
      in b0 1
      out lt 1
      out eq 1
      out gt 1
      e1 = xnor a1 b1
      e0 = xnor a0 b0
      eqv = and e1 e0
      na1 = not a1
      ltHigh = and na1 b1
      na0 = not a0
      ltLow = and na0 b0
      ltBoth = and e1 ltLow
      ltAll = or ltHigh ltBoth
      nb1 = not b1
      gtHigh = and a1 nb1
      nb0 = not b0
      gtLow = and a0 nb0
      gtBoth = and e1 gtLow
      gtAll = or gtHigh gtBoth
      lt <- ltAll
      eq <- eqv
      gt <- gtAll
```

### 2-4 译码器

译码器是「地址 → 选中」的翻译官。寄存器堆的写使能、片选信号、七段数码管的位选，都是它在干活。

端口：`a` 两位选择码；`o0` a=00 时为 1；`o1` a=01 时为 1；`o2` a=10 时为 1；`o3` a=11 时为 1

```
in a 2
      out o0 1
      out o1 1
      out o2 1
      out o3 1
      d = demux a n=4
      o0 <- d.o0
      o1 <- d.o1
      o2 <- d.o2
      o3 <- d.o3
```

### 4-2 优先编码器

中断控制器就是这么工作的：8 个外设同时举手，先服务编号大的。valid 那一位是「真的有人按吗」——少了它，000 会被误当成有人在按。

端口：`i0` 输入 0（优先级最低）；`i1` 输入 1；`i2` 输入 2；`i3` 输入 3（优先级最高）；`y` 最高优先级输入对应的编号；`v` 至少有一路输入为 1

```
in i0 1
      in i1 1
      in i2 1
      in i3 1
      out y 2
      out v 1
      y0 = or i1 i3
      y1 = or i2 i3
      any1 = or i0 i1
      any2 = or any1 i2
      any3 = or any2 i3
      m = merge y0 y1 width=2
      y <- m
      v <- any3
```

### 二进制转格雷码

格雷码解决「多个位同时翻转时的瞬时错值」。旋转编码器、异步 FIFO 的指针、卡诺图的行列顺序都靠它。

端口：`b` 4 位二进制码；`g` 4 位格雷码

```
in b 4
      out g 4
      s = split b width=4
      g3 = buf s.b3
      g2 = xor s.b3 s.b2
      g1 = xor s.b2 s.b1
      g0 = xor s.b1 s.b0
      m = merge g0 g1 g2 g3 width=4
      g <- m
```

### 格雷码转二进制

这是上一条的逆运算。会写正反两个方向，才算真的懂了一套编码——只会编码不会解码，是读不回来的数据。

端口：`g` 4 位格雷码；`b` 还原出的 4 位二进制码

```
in g 4
      out b 4
      s = split g width=4
      b3 = buf s.b3
      b2 = xor b3 s.b2
      b1 = xor b2 s.b1
      b0 = xor b1 s.b0
      m = merge b0 b1 b2 b3 width=4
      b <- m
```

### 三输入门组

把同一组输入接到三种门上，你会直观看到「门」不过是真值表的三种切法。元件参数的 inputs=3 也在这里第一次显形。

端口：`a` 输入 A；`b` 输入 B；`c` 输入 C；`all3` 三个都为 1；`any3` 至少一个为 1；`notAll` 不是三个都为 1

```
in a 1
      in b 1
      in c 1
      out all3 1
      out any3 1
      out notAll 1
      g1 = and a b c
      g2 = or a b c
      g3 = nand a b c
      all3 <- g1
      any3 <- g2
      notAll <- g3
```

### 四输入奇偶树

同样是四个数异或，串成一条链要 3 级延迟，做成树只要 2 级。这是「延迟 = 层数」这件事的最小例子。

端口：`a` 输入 A；`b` 输入 B；`c` 输入 C；`d` 输入 D；`p` 四个输入中 1 的个数为奇数

```
in a 1
      in b 1
      in c 1
      in d 1
      out p 1
      x1 = xor a b
      x2 = xor c d
      x3 = xor x1 x2
      p <- x3
```

### 4 位位序反转

FFT、CRC、串行收发里都要反转位序。它同时也是「split + merge 是一对互逆操作」最直白的演示。

端口：`a` 输入的 4 位；`y` 位序反转后的 4 位

```
in a 4
      out y 4
      s = split a width=4
      m = merge s.b3 s.b2 s.b1 s.b0 width=4
      y <- m
```

### 4 位加法器（带进位入出）

单个加法器只有把它级联起来才有意义。看清楚 ci/co 这一对接口，你就能拼出 8 位、32 位——位宽是可以「串」出来的，不是天生就有的。

端口：`a` 被加数（4 位）；`b` 加数（4 位）；`ci` 低位进位；`s` 和（4 位）；`co` 向高位的进位

```
in a 4
      in b 4
      in ci 1
      out s 4
      out co 1
      u = add a b ci
      s <- u.sum
      co <- u.cout
```

### 8 位行波加法器

这是「用窄元件搭宽数据通路」的标准动作：拆开、两半各算、再合回去。后面 32 位寄存器、64 位地址，全是这个套路叠出来的。

端口：`a` 被加数（8 位）；`b` 加数（8 位）；`s` 和（8 位）；`co` 最高位进位

```
in a 8
      in b 8
      out s 8
      out co 1
      sa = split a width=8
      sb = split b width=8
      al = merge sa.b0 sa.b1 sa.b2 sa.b3 width=4
      ah = merge sa.b4 sa.b5 sa.b6 sa.b7 width=4
      bl = merge sb.b0 sb.b1 sb.b2 sb.b3 width=4
      bh = merge sb.b4 sb.b5 sb.b6 sb.b7 width=4
      lo = add al bl
      hi = add ah bh lo.cout
      sl = split lo.sum width=4
      sh = split hi.sum width=4
      m = merge sl.b0 sl.b1 sl.b2 sl.b3 sh.b0 sh.b1 sh.b2 sh.b3 width=8
      s <- m
      co <- hi.cout
```

### 4 位减法器

有了借位，你就能做比较（a<b 就是借位=1）、能做补码减法、能做多字节大数减法。减法和比较其实是同一个电路。

端口：`a` 被减数；`b` 减数；`d` 差（4 位）；`br` 借位：a < b 时为 1

```
in a 4
      in b 4
      out d 4
      out br 1
      u = sub a b
      d <- u.diff
      br <- u.borrow
```

### 加减一体（sub 控制）

CPU 的 ALU 里只造一个加法器，减法靠「取反 + 进位入 1」借道。这个案例就是那句「减法即加法」的电路版，接上 sub 位就能亲眼看到进位方向反过来。

端口：`a` 左操作数；`b` 右操作数；`sub` 0 = 加，1 = 减；`y` 结果（8 位）；`co` 加减后的进位/无借位标志

```
in a 8
      in b 8
      in sub 1
      out y 8
      out co 1
      nb = not b
      bx = mux sub b nb
      u = add a bx sub
      y <- u.sum
      co <- u.cout
```

### 8 位增量器

程序计数器每拍就做这一件事。把它单独拎出来，你会看到 PC 的门数其实极少——难的是它背后的时序，而不是加法。

端口：`a` 输入值；`y` a + 1；`co` 从 0xFF 加到 0 时的进位

```
in a 8
      out y 8
      out co 1
      one = const width=8 value=1
      u = add a one
      y <- u.sum
      co <- u.cout
```

### 8 位取负（补码）

补码的核心恒等式。注意 0x80 取负还是 0x80——这不是 bug，是补码表示范围不对称的必然结果，能解释它的人就看懂了有符号数的边界。

端口：`a` 输入值；`y` -a 的补码表示

```
in a 8
      out y 8
      nb = not a
      one = const width=8 value=1
      u = add nb one
      y <- u.sum
```

### 8 位绝对值

一个 mux 加一个取负器就能算绝对值，这是「用符号位做数据选择」的第一个真实用途。它也解释了为什么 0x80 的绝对值还是 0x80。

端口：`a` 8 位有符号数；`y` 绝对值；`neg` 输入是否为负

```
in a 8
      out y 8
      out neg 1
      sa = split a width=8
      nb = not a
      one = const width=8 value=1
      u = add nb one
      o = mux sa.b7 a u.sum
      y <- o
      neg <- sa.b7
```

### 乘 10（移位加）

编译器天天干这件事：把「乘常数」翻译成移位和加。看懂它，你就知道为什么常数乘法比变量乘法快一个数量级。

端口：`a` 输入值；`y` (a × 10) 的低 8 位

```
in a 8
      out y 8
      k1 = const width=5 value=1
      k3 = const width=5 value=3
      s1 = shift a k1 dir=left
      s3 = shift a k3 dir=left
      u = add s1 s3
      y <- u.sum
```

### 4×4 乘法器（移位加）

乘法器不是魔法：b 的每一位决定「要不要把 a 加进来」，加的位置由位权决定。真实芯片用的是华莱士树，但结构思想与这里一模一样。

端口：`a` 被乘数（4 位）；`b` 乘数（4 位）；`p` 积（8 位）

```
in a 4
      in b 4
      out p 8
      sa = split a width=4
      sb = split b width=4
      z8 = const width=8 value=0
      z1 = const width=1 value=0
      ax = merge sa.b0 sa.b1 sa.b2 sa.b3 z1 z1 z1 z1 width=8
      t0 = mux sb.b0 z8 ax
      t1 = mux sb.b1 z8 ax
      t2 = mux sb.b2 z8 ax
      t3 = mux sb.b3 z8 ax
      k0 = const width=5 value=0
      k1 = const width=5 value=1
      k2 = const width=5 value=2
      k3 = const width=5 value=3
      q0 = shift t0 k0 dir=left
      q1 = shift t1 k1 dir=left
      q2 = shift t2 k2 dir=left
      q3 = shift t3 k3 dir=left
      u1 = add q0 q1
      u2 = add u1.sum q2
      u3 = add u2.sum q3
      p <- u3.sum
```

### 除 2：商与余数

除数是 2 的幂时，除法退化成移位的取舍问题：商在线上，余数在被丢掉的那一位。CPU 的除法指令要为「余数去哪」专门留一个寄存器。

端口：`a` 被除数；`q` 商（a >> 1）；`r` 余数（a 的最低位）

```
in a 8
      out q 8
      out r 1
      one = const width=5 value=1
      sh = shift a one dir=right
      sa = split a width=8
      q <- sh
      r <- sa.b0
```

### 8 位最小值

min/max 是向量化、图像、排序网络里出现最频繁的两个算子。它的电路只有两级，但把它串成一棵树，就能一条拍里求出 8 个数的最小值。

端口：`a` A；`b` B；`y` 较小者

```
in a 8
      in b 8
      out y 8
      c = cmp a b
      o = mux c.lt b a
      y <- o
```

### 8 位最大值

与 min 只差一根线的接法，但它是「归约树」的另一半：求最大值时，同一棵比较树可以同时算出最小值，代价是每个节点多一个 mux。

端口：`a` A；`b` B；`y` 较大者

```
in a 8
      in b 8
      out y 8
      c = cmp a b
      o = mux c.gt b a
      y <- o
```

### 平均而不溢出

直接 (a+b)/2 会在 a、b 都很大时溢出。教科书那个「取平均」写法为什么要拆成 and/xor，这个案例能让你亲手算出来。

端口：`a` A；`b` B；`y` (a + b) / 2 向下取整

```
in a 8
      in b 8
      out y 8
      an = and a b
      xo = xor a b
      one = const width=5 value=1
      sh = shift xo one dir=right
      u = add an sh
      y <- u.sum
```

### 饱和加法

图像处理、音频处理、DSP 全在用它：宁可削顶，也不要绕回 0 造成刺耳噪声或黑点。这是「错误处理可以是电路的一部分」的例子。

端口：`a` A；`b` B；`y` 饱和后的和（上限 255）；`sat` 发生饱和时为 1

```
in a 8
      in b 8
      out y 8
      out sat 1
      u = add a b
      cap = const width=8 value=255
      o = mux u.cout u.sum cap
      y <- o
      sat <- u.cout
```

### BCD 加法与校正

为什么电子表、收银机里要专门有 BCD 电路？因为 0.1 这样的十进制小数二进制存不准。这个案例把「+6 校正」这条规则变成电路，100 组输入全部验过。

端口：`a` BCD 数字 A（0..9）；`b` BCD 数字 B（0..9）；`y` 和的个位（0..9）；`carry` 十进制进位

```
in a 4
      in b 4
      out y 4
      out carry 1
      u = add a b
      ten = const width=4 value=10
      c = cmp u.sum ten
      ge = or c.gt c.eq
      big = or ge u.cout
      six = const width=4 value=6
      cor = add u.sum six
      o = mux big u.sum cor.sum
      y <- o
      carry <- big
```

### 8 位有符号比较器

同一个比较器，signed 一开一关，答案在 0x80 附近完全相反。这是「位的含义来自解释，而不是来自线」最锋利的一课。

端口：`a` A（补码）；`b` B（补码）；`lt` A < B；`eq` A = B；`gt` A > B

```
in a 8
      in b 8
      out lt 1
      out eq 1
      out gt 1
      c = cmp a b signed=true
      lt <- c.lt
      eq <- c.eq
      gt <- c.gt
```

### 4 操作 ALU

真实 ALU 就是「所有运算并行算出来，再由选择器挑一个」。并行的浪费换来一拍出结果——这个取舍是处理器设计里最经典的一笔。

端口：`a` 左操作数；`b` 右操作数；`op` 00 加 / 01 减 / 10 与 / 11 或；`y` 结果；`z` 结果为零标志

```
in a 8
      in b 8
      in op 2
      out y 8
      out z 1
      u1 = add a b
      u2 = sub a b
      u3 = and a b
      u4 = or a b
      m = mux op u1.sum u2.diff u3 u4
      zero = const width=8 value=0
      c = cmp m zero
      y <- m
      z <- c.eq
```

### 平方表（ROM 查表）

查表是「用存储换时间」的原型。着色器里的 LUT、神经网络里的查表量化、三角函数表，都是这一个动作的放大版。

端口：`a` 输入 0..15；`y` a 的平方（8 位）

```
in a 4
      out y 8
      r = rom a width=8 addrBits=4 data="0 1 4 9 16 25 36 49 64 81 100 121 144 169 196 225"
      y <- r
```

### 七段数码管译码

每一位对应一根线，看起来是纯查表，但它是「人能读懂电平」的第一步。把 7 根线接上真实数码管，你就有了一个能显示数字的机器。

端口：`d` 输入数字 0..15；`seg` 七段码：a b c d e f g，低位在前

```
in d 4
      out seg 7
      r = rom d width=7 addrBits=4 data="0x3F 0x06 0x5B 0x4F 0x66 0x6D 0x7D 0x07 0x7F 0x6F 0x77 0x7C 0x39 0x5E 0x79 0x71"
      seg <- r
```

### 区间夹取

边界检查是安全漏洞的头号来源。用两级比较器把值钉死在合法区间，是硬件里最便宜的一道护栏——摄像头、音频、电机控制里随处可见。

端口：`a` 输入值；`lo` 下限；`hi` 上限；`y` 夹取后的值

```
in a 8
      in lo 8
      in hi 8
      out y 8
      c1 = cmp a lo
      m1 = mux c1.lt a lo
      c2 = cmp m1 hi
      m2 = mux c2.gt m1 hi
      y <- m2
```

## 时序与状态（16 个）

| **门级 D 锁存器** | `dlatch-gate` | T3 | 3 | 5 | 两个与非门交叉反馈：clk 高时跟随 d，低时锁住。 |
| **上升沿检测** | `edge-detect` | T3 | 3 | 3 | 当前是 1、上一拍是 0 → 这一拍就是上升沿。 |

### 门级 D 锁存器

存储的第一性原理——把输出接回输入，电路就有了「记忆」。它也是「组合环」唯一合法的用法：仿真器会做不动点迭代，而这里恰好收敛。

端口：`clk` 门控：1 时透明，0 时保持；`d` 数据输入；`q` 锁存的值

```
in clk 1
      in d 1
      out q 1
      nd = not d
      s = nand d clk
      r = nand nd clk
      q1 = nand s q2
      q2 = nand r q1
      q <- q1
```

### 上升沿检测

把「事件」从「电平」里筛出来，是所有按键、串口起始位、中断触发的前提。它只用一个 D 触发器，却解决了一个真实世界的麻烦：电平会持续，事件只有一瞬。

端口：`clk` 时钟；`sig` 被观察的信号；`pulse` sig 刚刚由 0 变 1 时为 1（只维持到下一个时钟沿）

```
in clk 1
      in sig 1
      out pulse 1
      d1 = dff clk sig
      n1 = not d1
      p = and sig n1
      pulse <- p
```

### 单脉冲发生器

按一下只算一次——长按不会连发。这是「边沿触发」在交互上的直接价值，也是键盘、菜单、计数器按钮必须做的处理。

端口：`clk` 时钟；`btn` 按键电平；`y` 上升沿之后的下一拍输出一个高电平

```
in clk 1
      in btn 1
      out y 1
      d1 = dff clk btn
      d2 = dff clk d1
      n2 = not d2
      o = and d1 n2
      y <- o
```

### 二分频器

时钟分频是「用一条时钟造出多条时钟」的最简手段。它也解释了为什么 T 触发器只需要一个输入：翻转本身就是信息。

端口：`clk` 输入时钟；`q` 输出方波，周期是输入的两倍

```
in clk 1
      out q 1
      one = const width=1 value=1
      t = tff clk one
      q <- t
```

### 四分频器

分频链是定时器的心跳。注意它用的是**计数器取位**而不是「触发器的时钟接前一级的输出」——后者叫纹波时钟，会出现毛刺，是现代同步设计要避开的做法。

端口：`clk` 输入时钟；`q` 4 分频方波（计数器最高位）

```
in clk 1
      out q 1
      one = const width=1 value=1
      zero = const width=1 value=0
      c = counter clk one zero width=2
      s = split c.out width=2
      q <- s.b1
```

### 4 位环形计数器

独热状态机比二进制编码多用触发器，但每个状态的译码只有一根线、没有竞争。FPGA 里的状态机大量用这个结构。

端口：`clk` 时钟；`o0` 第 0 拍亮；`o1` 第 1 拍亮；`o2` 第 2 拍亮；`o3` 第 3 拍亮

```
in clk 1
      out o0 1
      out o1 1
      out o2 1
      out o3 1
      one = const width=1 value=1
      zero = const width=1 value=0
      c = counter clk one zero width=2
      d = demux c.out n=4
      o0 <- d.o0
      o1 <- d.o1
      o2 <- d.o2
      o3 <- d.o3
```

### 约翰逊计数器

N 个触发器能表示 2^N 个状态，但约翰逊只用 N 个就绕出 2N 个、且相邻状态只变一位。旧式接口电路里常拿它当时序发生器。

端口：`clk` 时钟；`q0` 第 0 位（最新移入，取反于 q3）；`q1` 第 1 位；`q2` 第 2 位；`q3` 第 3 位（最旧）

```
in clk 1
      out q0 1
      out q1 1
      out q2 1
      out q3 1
      fb = not d3
      d0 = dff clk fb
      d1 = dff clk d0
      d2 = dff clk d1
      d3 = dff clk d2
      q0 <- d0
      q1 <- d1
      q2 <- d2
      q3 <- d3
```

### 模 10 计数器

「数到 N 归零」是秒表、分频、波特率发生器的共同骨架。它的精髓在于：计数器本身只会溢出回绕，是**比较器 + 复位**给了它模数。

端口：`clk` 时钟；`out` 当前计数值 0..9

```
in clk 1
      out out 4
      one = const width=1 value=1
      zero = const width=1 value=0
      nine = const width=4 value=9
      c = counter clk one eq width=4
      e = cmp c.out nine
      let eq = e.eq
      out <- c.out
```

### PWM 占空比发生器

数字电路怎么调亮度、调转速、调音量？不是调电压，而是调「高电平占多少比例」。PWM 是数字世界模拟连续量的标准桥。

端口：`clk` 时钟；`duty` 占空比 0..15（每 16 拍里高电平的拍数）；`out` PWM 波形；`cnt` 当前计数值（便于观察锯齿）

```
in clk 1
      in duty 4
      out out 1
      out cnt 4
      one = const width=1 value=1
      zero = const width=1 value=0
      c = counter clk one zero width=4
      lt = cmp c.out duty
      out <- lt.lt
      cnt <- c.out
```

### 序列检测器（1011）

这是状态机的「暴力版」：不压缩状态，直接把历史摊开比对。它好懂、好改、好验证，位宽小的时候完全够用——而真状态机的化简，本质就是把这张表压到最少状态。

端口：`clk` 时钟；`din` 串行输入位；`hit` 最近四位正好是 1011

```
in clk 1
      in din 1
      out hit 1
      f0 = dff clk din
      f1 = dff clk f0
      f2 = dff clk f1
      f3 = dff clk f2
      n2 = not f2
      a1 = and f3 n2
      a2 = and a1 f1
      a3 = and a2 f0
      hit <- a3
```

### 交通灯状态机

状态机的最小可用形态：一个计数器记状态、一个译码器把状态变成输出。加上 en 之后它还能「暂停」——这是所有控制器都有的使能语义。

端口：`clk` 时钟；`en` 1 = 继续走，0 = 停在当前状态；`red` 红灯；`green` 绿灯；`yellow` 黄灯

```
in clk 1
      in en 1
      out red 1
      out green 1
      out yellow 1
      zero = const width=1 value=0
      two = const width=2 value=2
      s = counter clk en rst width=2
      e = cmp s.out two
      let rst = e.eq
      d = demux s.out n=3
      red <- d.o0
      green <- d.o1
      yellow <- d.o2
```

### 两级同步器

异步信号直接进逻辑会出现亚稳态——触发器可能停在 0 和 1 之间。两级同步器把「可能出错」压缩成「可能慢一拍」。每个跨时钟域接口的第一行代码都是它。

端口：`clk` 本地时钟；`async_in` 异步输入（来自别的时钟域）；`sync` 同步化后的值（延迟两拍）

```
in clk 1
      in async_in 1
      out sync 1
      f1 = dff clk async_in
      f2 = dff clk f1
      sync <- f2
```

### 长按检测

短按、长按、双击的区分全靠计数。这个案例把「时间」变成了「拍数」——硬件里没有秒，只有时钟周期。

端口：`clk` 时钟；`btn` 按键电平；`held` 已连续按住 ≥4 拍；`count` 当前连续按住的拍数（0..7）

```
in clk 1
      in btn 1
      out held 1
      out count 3
      one = const width=1 value=1
      nbtn = not btn
      n4 = const width=3 value=4
      c = counter clk btn nbtn width=3
      e = cmp c.out n4
      ge = or e.eq e.gt
      held <- ge
      count <- c.out
```

### 脉冲展宽器

很多外设只认「持续足够久」的电平，而 CPU 给出的是一个时钟周期的写脉冲。展宽器就是这两者之间的翻译，也是「用一个计数器把离散事件铺成时间窗」的入门。

端口：`clk` 时钟；`trig` 触发脉冲（可以只有 1 拍）；`busy` 最近 4 拍内触发过就为 1

```
in clk 1
      in trig 1
      out busy 1
      f1 = dff clk trig
      f2 = dff clk f1
      f3 = dff clk f2
      f4 = dff clk f3
      o1 = or trig f1
      o2 = or o1 f2
      o3 = or o2 f3
      o4 = or o3 f4
      busy <- o4
```

### 三拍多数去抖

机械按键按下去的几毫秒里会弹跳十几次。软件延时去抖会卡住 CPU，硬件多数表决不会。这个案例把「可靠性」写成电路，也只有 4 个元件。

端口：`clk` 时钟；`raw` 原始按键信号（带抖动）；`stable` 去抖后的稳定电平

```
in clk 1
      in raw 1
      out stable 1
      d1 = dff clk raw
      d2 = dff clk d1
      d3 = dff clk d2
      a1 = and d1 d2
      a2 = and d2 d3
      a3 = and d1 d3
      o1 = or a1 a2
      o2 = or o1 a3
      stable <- o2
```

### 4×8 寄存器堆（1 写 1 读）

「读要快、写要稳」是寄存器堆的全部设计目标：读走组合逻辑，一拍内出结果；写走时钟沿，不会被毛刺写坏。四个寄存器 + 一个写译码 + 一个读多路，就是 CPU 里那 8 个寄存器的同一套结构。

端口：`clk` 写时钟；`we` 写使能；`waddr` 写地址（2 位 = 4 个寄存器）；`wdata` 写入数据（8 位）；`raddr` 读地址；`rdata` 读出的数据（组合输出）

```
in clk 1
      in we 1
      in waddr 2
      in wdata 8
      in raddr 2
      out rdata 8
      d = demux waddr n=4
      l0 = and we d.o0
      l1 = and we d.o1
      l2 = and we d.o2
      l3 = and we d.o3
      r0 = reg clk l0 wdata
      r1 = reg clk l1 wdata
      r2 = reg clk l2 wdata
      r3 = reg clk l3 wdata
      m = mux raddr r0 r1 r2 r3
      rdata <- m
```

## 总线与选择（10 个）

多路复用、扩展、移位、仲裁：宽线与窄线之间的调度

| 案例 | id | 层 | 端口 | 元件 | 一句话 |
|---|---|---|---|---|---|
| **四选一数据通路（8 位）** | `mux4x8` | T2 | 6 | 1 | 四路 8 位数据并排，两位选择码挑一路出去。 |
| **一分四（未选中输出 0）** | `demux4x8` | T2 | 6 | 6 | 一路数据 + 两位目的地址：只有被选中的那一路拿到数据。 |
| **字节交换** | `byteswap` | T2 | 2 | 2 | 16 位里高字节和低字节对调。 |
| **符号扩展到 16 位** | `signext8-16` | T2 | 2 | 2 | 把 8 位的最高位复制 8 份填满高位：-1 还是 -1。 |
| **零扩展到 16 位** | `zeroext8-16` | T2 | 2 | 3 | 高位一律填 0：无符号数变宽。 |
| **4 位移位器（0..3 位）** | `shl4` | T3 | 3 | 6 | 先算出三个「移好位」的候选值，再用一个四选一挑出来。 |
| **4 位循环右移** | `ror4` | T3 | 3 | 5 | 移出去的那一位，从另一边补回来。 |
| **位选择器** | `bitselect8` | T2 | 3 | 2 | 8 位里按编号挑一位出来，编号 0..7。 |
| **四路优先级仲裁** | `arbiter4` | T3 | 9 | 7 | 四路同时请求时，只授权编号最小的那一路。 |
| **下一地址多路** | `addrmux` | T3 | 4 | 1 | 下一个取指地址：要么 PC+1，要么跳转目标。 |

### 四选一数据通路（8 位）

总线上的数据永远是「多路来源、一个去处」。这一级选择器就是数据通路的十字路口——CPU 里寄存器读口、ALU 输入、写回通路各有一个。

端口：`s` 选择码 00..11；`a` 第 0 路；`b` 第 1 路；`c` 第 2 路；`d` 第 3 路；`y` 选中的 8 位

```
in s 2
      in a 8
      in b 8
      in c 8
      in d 8
      out y 8
      m = mux s a b c d
      y <- m
```

### 一分四（未选中输出 0）

写回通路就是这么工作的：ALU 结果只有一份，但要能写进 4 个不同的寄存器。没被选中的目的地必须拿到 0，而不是「保持旧值」——这里的门控就是这个语义。

端口：`s` 目的地址；`d` 8 位数据；`o0` 第 0 路输出；`o1` 第 1 路输出；`o2` 第 2 路输出；`o3` 第 3 路输出

```
in s 2
      in d 8
      out o0 8
      out o1 8
      out o2 8
      out o3 8
      z = const width=8 value=0
      e = demux s n=4
      g0 = mux e.o0 z d
      g1 = mux e.o1 z d
      g2 = mux e.o2 z d
      g3 = mux e.o3 z d
      o0 <- g0
      o1 <- g1
      o2 <- g2
      o3 <- g3
```

### 字节交换

大端小端之争落到电路上就是这一行接线。网络协议用大端、x86 用小端，两边通话时必须有人做这件事——它便宜到只有一根线都不用，只需要换个接法。

端口：`w` 输入的 16 位；`y` 高低字节互换后的 16 位

```
in w 16
      out y 16
      s = split w width=16
      m = merge s.b8 s.b9 s.b10 s.b11 s.b12 s.b13 s.b14 s.b15 s.b0 s.b1 s.b2 s.b3 s.b4 s.b5 s.b6 s.b7 width=16
      y <- m
```

### 符号扩展到 16 位

有符号数变宽时必须做符号扩展，否则 -1（0xFF）会变成 255。处理器里的 lb/lh 指令就干这个，写错了就是那种「只有负数出错」的诡异 bug。

端口：`a` 8 位补码；`y` 16 位补码，数值不变

```
in a 8
      out y 16
      s = split a width=8
      m = merge s.b0 s.b1 s.b2 s.b3 s.b4 s.b5 s.b6 s.b7 s.b7 s.b7 s.b7 s.b7 s.b7 s.b7 s.b7 s.b7 width=16
      y <- m
```

### 零扩展到 16 位

与符号扩展只差「填什么」，但对 0x80 以上的值结果完全不同。选错扩展方式，是汇编作业里最经典的一类错。

端口：`a` 8 位无符号数；`y` 16 位无符号数

```
in a 8
      out y 16
      s = split a width=8
      z = const width=1 value=0
      m = merge s.b0 s.b1 s.b2 s.b3 s.b4 s.b5 s.b6 s.b7 z z z z z z z z width=16
      y <- m
```

### 4 位移位器（0..3 位）

这就是桶形移位器的全部思想：把移位量拆成「各移位一次」的候选，用选择器代替多次串行移位。4 位只要 2 级，32 位也只要 5 级。

端口：`a` 4 位输入；`sh` 左移位数 0..3；`y` 左移结果（低位补 0）

```
in a 4
      in sh 2
      out y 4
      s = split a width=4
      c0 = const width=1 value=0
      l1 = merge c0 s.b0 s.b1 s.b2 width=4
      l2 = merge c0 c0 s.b0 s.b1 width=4
      l3 = merge c0 c0 c0 s.b0 width=4
      m = mux sh a l1 l2 l3
      y <- m
```

### 4 位循环右移

循环移位在密码学里随处可见（AES、SHA 都在转）。它和普通右移只差「被移出的位去哪」——而这一点决定了信息不丢失。

端口：`a` 4 位输入；`n` 循环右移位数 0..3；`y` 结果

```
in a 4
      in n 2
      out y 4
      s = split a width=4
      r1 = merge s.b1 s.b2 s.b3 s.b0 width=4
      r2 = merge s.b2 s.b3 s.b0 s.b1 width=4
      r3 = merge s.b3 s.b0 s.b1 s.b2 width=4
      m = mux n a r1 r2 r3
      y <- m
```

### 位选择器

位图、标志寄存器、协议解析都要「取第 N 位」。它本质是一个 8 选 1，只不过每路只有 1 位宽——总线的宽度决定了选择器的形状。

端口：`a` 8 位数据；`i` 位编号 0..7；`bit` 被选中的那一位

```
in a 8
      in i 3
      out bit 1
      s = split a width=8
      m = mux i s.b0 s.b1 s.b2 s.b3 s.b4 s.b5 s.b6 s.b7
      bit <- m
```

### 四路优先级仲裁

一条总线同一时刻只能有一个主人。仲裁器就是那个「谁先说话」的裁判。优先级仲裁是所有共享资源（内存总线、DMA、中断线）都必须有的公平性装置。

端口：`r0` 请求 0（最高优先级）；`r1` 请求 1；`r2` 请求 2；`r3` 请求 3；`g0` 授权 0；`g1` 授权 1；`g2` 授权 2；`g3` 授权 3；`any` 至少有一路在请求

```
in r0 1
      in r1 1
      in r2 1
      in r3 1
      out g0 1
      out g1 1
      out g2 1
      out g3 1
      out any 1
      n0 = not r0
      n1 = not r1
      n2 = not r2
      g0 <- r0
      a1 = and r1 n0
      g1 <- a1
      a2 = and r2 n0 n1
      g2 <- a2
      a3 = and r3 n0 n1 n2
      g3 <- a3
      o = or r0 r1 r2 r3
      any <- o
```

### 下一地址多路

CPU 每拍都要回答「下一条指令在哪」。这个二选一就是取指阶段的核心决策点，也是所有分支预测硬件试图提前猜的那一位。

端口：`sel` 0 = 顺序执行（PC+1），1 = 跳转；`pc` 顺序地址；`tgt` 跳转目标；`addr` 真正送进存储器的地址

```
in sel 1
      in pc 8
      in tgt 8
      out addr 8
      m = mux sel pc tgt
      addr <- m
```

## 存储与介质（12 个）

RAM/ROM/FIFO/栈，以及电容、浮栅、盘片的物理模型

| 案例 | id | 层 | 端口 | 元件 | 一句话 |
|---|---|---|---|---|---|
| **16×8 RAM（单口读写）** | `ram16x8` | T3 | 5 | 1 | 一个地址、一条数据线：写要时钟沿，读是组合的。 |
| **查找表（统计 4 位里几个 1）** | `romlut` | T3 | 2 | 1 | 任意函数都可以烧成一张表：输入当地址，输出当数据。 |
| **字符发生器 ROM** | `romchars` | T3 | 2 | 1 | 地址 0..9 对应 HELLO,Z16! 的 ASCII 码。 |
| **栈（栈指针 + RAM）** | `stack` | T3 | 7 | 10 | push 先写当前槽位再自增；pop 先自减，读出来的就是新栈顶。 |
| **DRAM 单元（1T1C）** | `dram-cell` | T4 | 4 | 3 | 一个电容存一个电平：不刷新就会漏掉。 |
| **感应放大器** | `dram-sense` | T4 | 5 | 3 | 位线上的半电平，被放大成满幅 0/1 才能被数字电路采信。 |
| **刷新控制器** | `dram-refresh` | T4 | 3 | 1 | 每 window 拍轮询到下一行，把 64ms 离散成拍数。 |
| **浮栅单元（写慢、擦成块、有寿命）** | `flash-cell` | T4 | 6 | 1 | 编程要连续 2 拍脉宽，擦除 1 拍就够，每次擦除记一次 P/E。 |
| **磁盘寻道（磁头 + 盘面）** | `disk-seek` | T4 | 5 | 2 | 盘面每拍转一格，step=1 时磁头每拍挪一道。 |
| **磁盘读扇区** | `disk-read` | T4 | 7 | 1 | 磁头下压着什么就读什么：读到的值取决于磁道和扇区的当前相位。 |
| **Cache 标签比较** | `cache-tag` | T4 | 5 | 5 | 写进去的标签 vs 这次要访存的标签：相等且有效才算命中。 |
| **存储映射（RAM / ROM 二选一）** | `mem-map` | T3 | 5 | 2 | 地址最高位当片选：高半区走 ROM，低半区走 RAM。 |

### 16×8 RAM（单口读写）

单口 RAM 的读写抢同一个地址口——这正是真实存储器的形状。看懂「读快写慢、地址只有一个」，你就明白为什么 CPU 里要有独立的指令/数据通路，以及为什么 DMA 会和 CPU 抢总线。

端口：`clk` 写时钟；`we` 写使能（1 = 在这个沿写入）；`addr` 地址 0..15；`din` 写入数据；`dout` 该地址当前内容（组合读出）

```
in clk 1
      in we 1
      in addr 4
      in din 8
      out dout 8
      m = ram clk we addr din width=8 addrBits=4
      dout <- m.dout
```

### 查找表（统计 4 位里几个 1）

LUT 是 FPGA 的基本单元，也是「用存储实现计算」的通用办法。popcount 这种没有简洁布尔式的函数，查表反而最快。

端口：`a` 4 位输入；`y` 其中 1 的个数（0..4）

```
in a 4
      out y 8
      r = rom a width=8 addrBits=4 data="0 1 1 2 1 2 2 3 1 2 2 3 2 3 3 4"
      y <- r
```

### 字符发生器 ROM

「把字模/字符串烧进 ROM」是显示器的第一课。点阵字库本质就是同一个结构：地址是字符编号，数据是点阵行。

端口：`a` 字符编号 0..9；`y` 该字符的 ASCII 码

```
in a 4
      out y 8
      r = rom a width=8 addrBits=4 data="0x48 0x45 0x4C 0x4C 0x4F 0x2C 0x5A 0x31 0x36 0x21 0x20 0x20 0x20 0x20 0x20 0x20"
      y <- r
```

### 栈（栈指针 + RAM）

函数调用、局部变量、返回地址全靠它。注意 sp 指向「下一个空槽」——这个约定比「指向栈顶」少一次地址运算，也是很多真实 ISA 的选择。

端口：`clk` 时钟；`push` 压栈（写 din 到 mem[sp]，然后 sp+1）；`pop` 出栈（sp-1，dout 随即显示新栈顶）；`din` 压入的数据；`dout` mem[sp] 的内容：pop 之后就是新栈顶；`sp` 栈指针（= 已压入的元素个数）；`empty` 栈空（sp = 0）

```
in clk 1
      in push 1
      in pop 1
      in din 8
      out dout 8
      out sp 4
      out empty 1
      one = const width=4 value=1
      inc = add sph one
      dec = sub sph one
      t1 = mux push sph inc.sum
      dn = mux pop t1 dec.diff
      load = or push pop
      sph = reg clk load dn width=4
      m = ram clk push sph din width=8 addrBits=4
      zero = const width=4 value=0
      e = cmp sph zero
      dout <- m.dout
      sp <- sph
      empty <- e.eq
```

### DRAM 单元（1T1C）

内存不是「一直记得」，而是「一直在漏、一直在补」。把 leakN 改小，你能亲眼看到数据在几拍之内烂掉——这就是为什么 DRAM 必须每隔 64ms 把所有行刷一遍。

端口：`clk` 字线时钟；`we` 写使能（EN=1 时在时钟沿采样位线）；`d` 写入的位；`q` 电容当前电平：0 / 1 / 2 对应 GND / VDD2 / VDD

```
in clk 1
      in we 1
      in d 1
      out q 2
      z = const width=1 value=0
      bl = merge z d width=2
      cell = CAPCELL we clk bl leakN=3
      q <- cell.Q
```

### 感应放大器

电容只有几十飞法，读出来的信号只有几十毫伏。感应放大器把这点差别放大成满幅——它是 DRAM 里唯一「模拟」的那一环，也是读操作必须先预充电的原因。

端口：`clk` 时钟；`bl` 位线电平 0/1/2（GND / VDD2 / VDD）；`se` 感应使能；`q` 放大后的电平（满幅 0 或 2）；`half` 单元里的原始电平

```
in clk 1
      in bl 2
      in se 1
      out q 2
      out half 2
      one = const width=1 value=1
      cell = CAPCELL one clk bl leakN=16
      sa = SENSEAMP cell.Q se
      q <- sa.OUT
      half <- cell.Q
```

### 刷新控制器

8 行 8 个窗口，就是一个「行地址扫描器」。真实 DRAM 是 8192 行、64ms 扫完，于是每行 7.8µs 就得刷一次——这些数字决定了内存控制器的面积和功耗。

端口：`clk` 时钟；`rst` 复位到第 0 行；`row` 当前该刷新的行号

```
in clk 1
      in rst 1
      out row 3
      r = REFCTRL clk rst addrBits=3 window=2
      row <- r.ROW
```

### 浮栅单元（写慢、擦成块、有寿命）

为什么 SSD 写久了会坏？因为浮栅每次擦写都会在氧化层上留一道伤。P/E 超过上限，这个单元就废了——这不是软件抽象，是物理事实。

端口：`clk` 时钟；`prog` 编程脉冲（要持续 programTicks 拍才置 0）；`erase` 擦除（上升沿置 1，并计一次 P/E）；`q` 存储位；`pe` 已用 P/E 次数；`bad` P/E 超过寿命上限

```
in clk 1
      in prog 1
      in erase 1
      out q 1
      out pe 8
      out bad 1
      f = FGCELL clk prog erase programTicks=2 peLimit=3
      q <- f.Q
      pe <- f.PE
      bad <- f.STS
```

### 磁盘寻道（磁头 + 盘面）

机械硬盘的延迟不是因为「数据难找」，而是因为物理运动：寻道要挪磁头、旋转要等扇区转过来。把延迟写成拍数，你就能算清楚为什么随机读比顺序读慢两个数量级。

端口：`clk` 时钟；`tgt` 目标磁道；`step` 磁头步进使能；`trk` 当前磁道；`rot` 当前扇区（每拍 +1）

```
in clk 1
      in tgt 2
      in step 1
      out trk 8
      out rot 8
      zero = const width=1 value=0
      p = PLATTER clk tgt step zero addrBits=2 sectors=4 data="0x11 0x12 0x13 0x14 0x21 0x22 0x23 0x24 0x31 0x32 0x33 0x34 0x41 0x42 0x43 0x44"
      trk <- p.TRK
      rot <- p.ROT
```

### 磁盘读扇区

同一个逻辑地址，读两次可能拿到不同的中间结果——因为你没等到正确的时机。这就是「时序」在存储里的本色：数据不是被取出来的，是被「转过来」的。

端口：`clk` 时钟；`tgt` 目标磁道；`step` 磁头步进；`rd` 读使能；`q` 磁头下方扇区的内容；`trk` 当前磁道；`rot` 当前扇区

```
in clk 1
      in tgt 2
      in step 1
      in rd 1
      out q 8
      out trk 8
      out rot 8
      p = PLATTER clk tgt step rd addrBits=2 sectors=4 data="0x11 0x12 0x13 0x14 0x21 0x22 0x23 0x24 0x31 0x32 0x33 0x34 0x41 0x42 0x43 0x44"
      q <- p.Q
      trk <- p.TRK
      rot <- p.ROT
```

### Cache 标签比较

缓存的全部魔法就是「先比较，再决定要不要去主存取」。有效位是为了区分「空行」和「标签恰好是 0 的行」——少了它，冷启动第一次访问就会假命中。

端口：`clk` 时钟；`we` 写入标签（同时把有效位置 1）；`tag_in` 本次访问的标签；`hit` 命中（有效且标签相等）；`tag_out` 当前存着的标签

```
in clk 1
      in we 1
      in tag_in 4
      out hit 1
      out tag_out 4
      t = reg clk we tag_in width=4
      vs = or v we
      v = dff clk vs
      c = cmp tag_in t
      o = and v c.eq
      hit <- o
      tag_out <- t
```

### 存储映射（RAM / ROM 二选一）

「地址空间」不是抽象概念，而是最高几位接到哪个片选脚。看懂这一根线，你就懂为什么程序段放在 0x0000、栈放在高地址、以及为什么野指针会踩到别的设备。

端口：`addr` 8 位地址；`ram_d` RAM 的输出；`rom_d` ROM 的输出；`d` 按地址选中的那一路数据；`from_rom` 这次访问落在 ROM 区

```
in addr 8
      in ram_d 8
      in rom_d 8
      out d 8
      out from_rom 1
      s = split addr width=8
      m = mux s.b7 ram_d rom_d
      d <- m
      from_rom <- s.b7
```

### 程序计数器

PC 是「程序」这个概念在硬件里的唯一实体。它的三个优先级（复位 > 装载 > +1）就是指令流的全部控制语义。

端口：`clk` 时钟；`ld` 装载跳转目标；`din` 跳转目标地址；`rst` 复位到 0（优先级最高）；`pc` 当前指令地址

```
in clk 1
      in ld 1
      in din 8
      in rst 1
      out pc 8
      one = const width=8 value=1
      zero = const width=8 value=0
      inc = add pcr one
      n1 = mux ld inc.sum din
      n2 = mux rst n1 zero
      one1 = const width=1 value=1
      pcr = reg clk one1 n2 width=8
      pc <- pcr
```

### 指令寄存器

为什么需要 IR？因为存储器只有一个地址口，取完指令地址就要变了。把指令搬进 IR，译码器才能在整拍里稳定地看它。

端口：`clk` 时钟；`ld` 装载（通常每拍都为 1）；`din` 取出的指令字节；`q` 当前指令

```
in clk 1
      in ld 1
      in din 8
      out q 8
      ir = reg clk ld din width=8
      q <- ir
```

### 条件码寄存器

标志位是「上一拍的结果」被下一拍使用的唯一通道。它也是流水线里最难处理的东西之一——因为它让每一条指令都隐式依赖前一条。

端口：`clk` 时钟；`ld` 锁存使能；`z` 零标志输入；`c` 进位标志输入；`n` 符号标志输入；`zf` 存住的零标志；`cf` 存住的进位；`nf` 存住的符号

```
in clk 1
      in ld 1
      in z 1
      in c 1
      in n 1
      out zf 1
      out cf 1
      out nf 1
      zr = reg clk ld z width=1
      cr = reg clk ld c width=1
      nr = reg clk ld n width=1
      zf <- zr
      cf <- cr
      nf <- nr
```

### 指令译码器（微码 ROM）

硬布线控制 vs 微码控制的分水岭就在这张表：改一条指令只需要改表里的一行，而不需要重新画电路。CISC 处理器几万条指令就是这么活下来的。

端口：`op` 操作码 0..15；`ctrl` 控制字（各 bit 对应一个控制信号）

```
in op 4
      out ctrl 8
      r = rom op width=8 addrBits=4 data="0x11 0x22 0x44 0x88 0x13 0x25 0x47 0x89 0x15 0x2A 0x54 0xA8 0x1F 0x3F 0x7F 0xFF"
      ctrl <- r
```

### 立即数符号扩展

addi r1, r0, -1 里的 -1 是 4 位 0xF。扩成 8 位时若补 0，程序会加上 15 而不是减 1——这类 bug 在真实 ISA 里叫「符号扩展错误」，编译器测试套件专门抓它。

端口：`imm` 4 位立即数（补码）；`y` 扩展后的 8 位

```
in imm 4
      out y 8
      s = split imm width=4
      m = merge s.b0 s.b1 s.b2 s.b3 s.b3 s.b3 s.b3 s.b3 width=8
      y <- m
```

### 跳转目标计算

相对跳转让代码可以整体搬家（位置无关）。它的代价就是一个加法器，收益是「同一份程序能装在任意地址」——动态库就是这么实现的。

端口：`pc` 当前地址；`off` 8 位偏移（补码）；`tgt` 跳转目标

```
in pc 8
      in off 8
      out tgt 8
      u = add pc off
      tgt <- u.sum
```

### 栈指针

SP 是唯一「由程序自己维护」的寄存器，也是函数调用约定里最容易出错的一个。它的三个动作就是一个三选一多路选择器。

端口：`clk` 时钟；`push` 压栈（SP+1）；`pop` 出栈（SP-1）；`sp` 当前栈指针

```
in clk 1
      in push 1
      in pop 1
      out sp 8
      one = const width=8 value=1
      inc = add spr one
      dec = sub spr one
      t1 = mux push spr inc.sum
      dn = mux pop t1 dec.diff
      load = or push pop
      spr = reg clk load dn width=8
      sp <- spr
```

### 内部总线多路

单总线 CPU 的全部时序就是在抢这一根线。多一个数据源，就多一位选择码、多一个时序冲突要避免。

端口：`sel` 00 ALU / 01 内存 / 10 立即数 / 11 PC；`alu` ALU 输出；`mem` 内存读出；`imm` 立即数；`pc` PC 值；`d` 上总线的数据

```
in sel 2
      in alu 8
      in mem 8
      in imm 8
      in pc 8
      out d 8
      m = mux sel alu mem imm pc
      d <- m
```

### 时钟分频（8 位）

把一个 100MHz 的时钟变成肉眼可见的 0.4Hz——这是「慢下来调试」的物理实现，也是所有定时器的第一级。

端口：`clk` 输入时钟；`slow` 分频后的慢时钟（最高位）

```
in clk 1
      out slow 1
      one = const width=1 value=1
      zero = const width=1 value=0
      c = counter clk one zero width=8
      s = split c.out width=8
      slow <- s.b7
```

### 中断控制器

中断是 CPU 唯一「愿意被动打断自己」的机制。优先级 + 向量号这两件事决定了系统的响应性——实时系统里调错一个优先级，就会出现「低优先级任务饿死」。

端口：`i0` 中断源 0（最高）；`i1` 中断源 1；`i2` 中断源 2；`i3` 中断源 3；`irq` 有中断待处理；`vec` 中断号（最高优先级那一路）

```
in i0 1
      in i1 1
      in i2 1
      in i3 1
      out irq 1
      out vec 2
      n0 = not i0
      n1 = not i1
      n2 = not i2
      g1 = and i1 n0
      g2 = and i2 n0 n1
      g3 = and i3 n0 n1 n2
      v0 = or g1 g3
      v1 = or g2 g3
      m = merge v0 v1 width=2
      o = or i0 i1 i2 i3
      irq <- o
      vec <- m
```

### 节拍发生器 T0–T3

微程序控制的核心就是「第几拍做什么」。T0 取指、T1 译码、T2 执行、T3 写回——把时间编成一组独热线，控制信号就是这些线与条件码的组合。

端口：`clk` 时钟；`rst` 回到 T0；`t0` 第 0 拍；`t1` 第 1 拍；`t2` 第 2 拍；`t3` 第 3 拍

```
in clk 1
      in rst 1
      out t0 1
      out t1 1
      out t2 1
      out t3 1
      one = const width=1 value=1
      c = counter clk one rst width=2
      d = demux c.out n=4
      t0 <- d.o0
      t1 <- d.o1
      t2 <- d.o2
      t3 <- d.o3
```

### 停机锁存

「停机」不是断电，而是不再给时钟。这个 3 元件的小电路解释了一个大问题：为什么有些 CPU 停机后还能被中断唤醒——因为唤醒它的不是时钟，而是另一条复位/中断路径。

端口：`clk` 时钟；`halt` 译码出的停机信号（1 拍即可）；`run` 0 = 已停机

```
in clk 1
      in halt 1
      out run 1
      hs = or h halt
      h = dff clk hs
      nr = not h
      run <- nr
```

## 显示与协议（10 个）

把电平变成人能读的东西：数码管、字符、CRC、汉明码

| 案例 | id | 层 | 端口 | 元件 | 一句话 |
|---|---|---|---|---|---|
| **字符终端输出** | `chardisp` | T2 | 4 | 1 | 把 8 位 ASCII 码打印到运行日志，同时原样送出。 |
| **十六进制日志** | `hex-log` | T2 | 4 | 1 | 把 4 位值按十六进制打到日志里。 |
| **流水灯** | `led-chase` | T3 | 3 | 6 | 一位亮着往前跑，跑到头再绕回来。 |
| **电平条（掩码表）** | `led-bar` | T2 | 2 | 1 | 输入 0..8，输出「前 N 位亮」的掩码。 |
| **串口发送（移位寄存器）** | `uart-tx` | T3 | 4 | 6 | 8 位并行数据每拍右移一位，最低位从 tx 出去。 |
| **CRC-8 校验** | `crc8` | T4 | 4 | 11 | 每来一位：左移、溢出位回卷、按多项式异或。 |
| **汉明码编码（7,4）** | `hamming-encode` | T4 | 2 | 5 | 4 位数据 + 3 位校验，插在 1/2/4 三个位置上。 |
| **汉明码检错（定位错误位）** | `hamming-check` | T4 | 3 | 7 | 三组校验各自算一次：哪个组合不对，错的就是第几位。 |
| **数码管动态扫描** | `seg-scan` | T3 | 5 | 4 | 两路数据轮流上同一组段码线，靠 com 快速切换。 |
| **计数显示器** | `count-display` | T3 | 3 | 6 | 0..9 循环计数，直接译成七段码显示。 |

### 字符终端输出

「让程序说话」是调试的第一需要。这个案例把 print 元件当成 CPU 的一个外设：写一次就打印一个字符——串口、printf、日志系统的同一件事。

端口：`clk` 时钟；`en` 使能（上升沿且 en=1 时打印）；`code` ASCII 码；`d` 直通输出（可接到别处）

```
in clk 1
      in en 1
      in code 8
      out d 8
      p = print clk en code radix=char
      d <- code
```

### 十六进制日志

调试寄存器时人看的是 0x1F 而不是 11111。同一个值换一种进制，认知负担差十倍——这就是为什么每个调试器都提供 radix 切换。

端口：`clk` 时钟；`en` 打印使能；`v` 4 位值；`d` 直通输出

```
in clk 1
      in en 1
      in v 4
      out d 4
      p = print clk en v radix=hex
      d <- v
```

### 流水灯

循环左移 + 一个寄存器，是「把时钟变成可见的节奏」的最短路径。它也是移位寄存器最好的入门——你能一眼看出每一位去了哪里。

端口：`clk` 时钟；`rst` 复位到只有最低位亮；`led` 8 位灯带

```
in clk 1
      in rst 1
      out led 8
      r = reg clk one nxt width=8
      s = split r width=8
      rot = merge s.b7 s.b0 s.b1 s.b2 s.b3 s.b4 s.b5 s.b6 width=8
      one8 = const width=8 value=1
      nxt = mux rst rot one8
      one = const width=1 value=1
      led <- r
```

### 电平条（掩码表）

音量条、进度条、电池格数全是这个查表。它的意义在于：人眼读「有几位亮」比读「二进制数」快得多。

端口：`n` 亮的格数 0..8；`bar` 灯带掩码

```
in n 4
      out bar 8
      r = rom n width=8 addrBits=4 data="0 1 3 7 15 31 63 127 255 255 255 255 255 255 255 255"
      bar <- r
```

### 串口发送（移位寄存器）

「并行变串行」只需要一个移位寄存器。真实 UART 在它外面再包一层起始位和停止位，本质没变——所以看懂这 5 个元件，你就看懂了波特率、LSB-first、以及为什么串口要约定速率。

端口：`clk` 时钟；`load` 装载新字节；`din` 要发送的字节；`tx` 串行输出（LSB 先出）

```
in clk 1
      in load 1
      in din 8
      out tx 1
      r = reg clk one nxt width=8
      one5 = const width=5 value=1
      sh = shift r one5 dir=right
      nxt = mux load sh din
      s = split r width=8
      one = const width=1 value=1
      tx <- s.b0
```

### CRC-8 校验

串口、以太网、ZIP、SSD 全在用 CRC。它比「求和校验」强的地方是：任何单比特错误一定能被发现，而加法校验对换位错误无能为力。

端口：`clk` 时钟；`bit_in` 串行输入位；`rst` 清零；`crc` 当前 CRC（每拍更新）

```
in clk 1
      in bit_in 1
      in rst 1
      out crc 8
      r = reg clk one nxt2 width=8
      s = split r width=8
      let msb = s.b7
      fb = xor bit_in msb
      poly = const width=8 value=7
      z8 = const width=8 value=0
      mask = mux fb z8 poly
      one5 = const width=5 value=1
      sh = shift r one5 dir=left
      x = xor sh mask
      nxt2 = mux rst x z8
      one = const width=1 value=1
      crc <- r
```

### 汉明码编码（7,4）

CRC 能发现错误，汉明码还能**指出哪一位错了**并当场纠正。ECC 内存就是每个字节多存 5 位，换来「单位翻转自愈」。

端口：`d` 4 位数据；`code` 7 位码字（c0..c6 依次为 p1 p2 d1 p4 d2 d3 d4）

```
in d 4
      out code 7
      sd = split d width=4
      p1 = xor sd.b0 sd.b1 sd.b3
      p2 = xor sd.b0 sd.b2 sd.b3
      p4 = xor sd.b1 sd.b2 sd.b3
      m = merge p1 p2 sd.b0 p4 sd.b1 sd.b2 sd.b3 width=7
      code <- m
```

### 汉明码检错（定位错误位）

这是「用 3 个比特编码 7 种可能」的经典设计：综合征的值直接就是出错位置的下标。硬件纠错之所以便宜，是因为它不需要搜索。

端口：`code` 7 位码字；`err` 出错位号（0 = 没错）；`ok` 无错

```
in code 7
      out err 3
      out ok 1
      sc = split code width=7
      s1 = xor sc.b0 sc.b2 sc.b4 sc.b6
      s2 = xor sc.b1 sc.b2 sc.b5 sc.b6
      s4 = xor sc.b3 sc.b4 sc.b5 sc.b6
      m = merge s1 s2 s4 width=3
      z = const width=3 value=0
      c = cmp m z
      err <- m
      ok <- c.eq
```

### 数码管动态扫描

为什么要「扫描」？因为段码线太贵——8 位数码管若都直连要 64 根线，扫描只要 8 + 8 根。代价是每位数只能亮 1/8 时间，亮度靠人眼暂留补上。

端口：`clk` 时钟；`d0` 左位数字；`d1` 右位数字；`seg` 七段码；`com` 当前亮的是哪一位（0 左 / 1 右）

```
in clk 1
      in d0 4
      in d1 4
      out seg 7
      out com 1
      one = const width=1 value=1
      t = tff clk one
      v = mux t d0 d1
      r = rom v width=7 addrBits=4 data="0x3F 0x06 0x5B 0x4F 0x66 0x6D 0x7D 0x07 0x7F 0x6F 0x77 0x7C 0x39 0x5E 0x79 0x71"
      seg <- r
      com <- t
```

### 计数显示器

计数器 + 译码器 + 显示器 = 一块秒表。把这三个模块连起来，你就有了第一个「自己会动的仪器」，也是所有实验箱上第一个做成的作品。

端口：`clk` 时钟；`cnt` 当前数字 0..9；`seg` 七段码

```
in clk 1
      out cnt 4
      out seg 7
      one = const width=1 value=1
      zero = const width=1 value=0
      nine = const width=4 value=9
      c = counter clk one rst width=4
      e = cmp c.out nine
      let rst = e.eq
      r = rom c.out width=7 addrBits=4 data="0x3F 0x06 0x5B 0x4F 0x66 0x6D 0x7D 0x07 0x7F 0x6F 0x77 0x7C 0x39 0x5E 0x79 0x71"
      cnt <- c.out
      seg <- r
```

## 整机与数据通路（4 个）

把前面 90 个案例焊起来，跑出一条真正的指令

| 案例 | id | 层 | 端口 | 元件 | 一句话 |
|---|---|---|---|---|---|
| **单周期数据通路** | `datapath` | T4 | 6 | 3 | 两个寄存器喂一个 ALU，结果直接出线——一拍算完。 |
| **累加器机** | `accumulator` | T4 | 4 | 4 | 每拍 acc = acc + imm：一条指令就是一台计算机。 |
| **计数器机（数到 N 就停）** | `counter-machine` | T4 | 4 | 6 | 自增到 N 之后保持不动，并给出 done 标志。 |
| **迷你 CPU（真的跑一段程序）** | `mini-cpu` | T4 | 5 | 11 | ROM 存程序、PC 取指、IR 锁指令、累加器执行、HALT 停机。 |

### 单周期数据通路

这是「处理器」的骨架图去掉控制逻辑之后剩下的部分。看清楚数据怎么从寄存器流进 ALU 再流出来，你就能自己往里加流水线寄存器，看延迟怎么被切成段。

端口：`clk` 时钟；`ld` 装载 A/B；`a_in` A 的输入；`b_in` B 的输入；`op` ALU 操作码（0 加 1 减 2 与 3 或 4 异或 5 非 6 左移 7 右移）；`y` ALU 结果

```
in clk 1
      in ld 1
      in a_in 8
      in b_in 8
      in op 3
      out y 8
      ra = reg clk ld a_in width=8
      rb = reg clk ld b_in width=8
      u = alu ra rb op
      y <- u.out
```

### 累加器机

最早的计算机（EDSAC 那一代）只有一个累加器。它证明了一件事：只要有一个能加法的寄存器加一个能取指的顺序，就足以算出任何可计算的东西。

端口：`clk` 时钟；`en` 累加使能；`imm` 加数；`acc` 累加结果

```
in clk 1
      in en 1
      in imm 8
      out acc 8
      u = add accr imm
      nxt = mux en accr u.sum
      one = const width=1 value=1
      accr = reg clk one nxt width=8
      acc <- accr
```

### 计数器机（数到 N 就停）

这就是「循环」在硬件里的样子：比较 + 条件装载。软件里的 for 循环被编译器展开之后，控制流剩下的就是这套自增、比较、分支的组合。

端口：`clk` 时钟；`n` 目标值；`cnt` 当前计数；`done` 已经数到 N

```
in clk 1
      in n 8
      out cnt 8
      out done 1
      one = const width=8 value=1
      u = add cntr one
      c = cmp cntr n
      nxt = mux c.eq u.sum cntr
      one1 = const width=1 value=1
      cntr = reg clk one1 nxt width=8
      cnt <- cntr
      done <- c.eq
```

### 迷你 CPU（真的跑一段程序）

这台机器只有 5 个零件，却能执行「1+2+3 然后停机」——它把前面 96 个案例全部串了起来：ROM 是存储、PC 是计数器、IR 是寄存器、累加是加法器、HALT 是锁存。看懂它，你就看懂了什么叫「存储程序」。

端口：`clk` 时钟；`rst` 复位（PC 归零）；`acc` 累加器（这就是这台机器的全部状态）；`pc` 程序计数器；`halted` 已经执行到 HALT

```
in clk 1
      in rst 1
      out acc 8
      out pc 3
      out halted 1
      prog = rom pcr width=8 addrBits=3 data="0x01 0x02 0x03 0x80 0x00 0x00 0x00 0x00"
      one1 = const width=1 value=1
      pcr = counter clk en rst width=3
      ir = reg clk one1 prog width=8
      si = split ir width=8
      let haltb = si.b7
      imm = merge si.b0 si.b1 si.b2 si.b3 si.b4 si.b5 si.b6 width=7
      hs = or haltb h
      h = dff clk hs
      nen = not h
      let en = nen
      sum = add accr imm
      accr = reg clk nen sum width=8
      acc <- accr
      pc <- pcr
      halted <- h
```
