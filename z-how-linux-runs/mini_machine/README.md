# mini_machine —— 把零件焊成一台机器（mini 机器）

> cpu_work 造出了「算」（CPU），memory_work 造出了「记」（存储）。
> 但零件躺在桌上不等于机器。本系列回答最后一个硬件问题：**怎么把它们焊起来，让一台纯硬件的机器自己转起来**——目标物：一颗单片机（MCU）。
> 读完本系列，你将站在主系列 01-硬件规约的**制造者视角**：规约不是天上掉下来的，是我们在电路上一步步做出的取舍。

## 为什么需要这个系列

- 主系列 01 讲了「CPU 只会一件事 + 四条通道」——但**通道是谁修的？**（总线、中断控制器、设备寄存器）
- cpu_work 的 CPU 停在「取指-执行」——但**指令从哪来、时钟谁给、上电第一拍做什么？**
- memory_work 讲了介质——但 **SRAM 与 Flash 怎么同时挂在一个 CPU 旁边？**
- 本系列补上：**总线、时钟、复位、外设、中断、DMA、上电序列**——一台机器的骨肉相连。

## 我们的目标机器

虚构但**完全真实可造**：一颗典型的 32 位 MCU（心脏按 Cortex-M0/M3 类，外设按 STM32 类惯例），上面有：

```
        ┌──────────────────────────────────────────┐
        │                 一颗 MCU 芯片              │
        │  ┌─────┐  ┌──────┐  ┌───────┐  ┌───────┐  │
        │  │CPU核│  │ SRAM │  │ Flash │  │ 中断  │  │
        │  └──┬──┘  └──┬───┘  └───┬───┘  │控制器 │  │
        │     └────────┴───┬──────┴──────└──┬────┘  │
        │              AHB 高速总线          │       │
        │                  │(桥)            │       │
        │              APB 外设总线          │       │
        │      ┌────┬────┬─────┬─────┬────┐ │       │
        │      │GPIO│UART│Timer│ ADC │DMA │─┘       │
        │      └────┴────┴─────┴─────┴────┘         │
        └──────────────────────────────────────────┘
           晶振 ── 复位电路 ── 电源 —— 芯片外面三个小零件
```

## 读法

- 需要零件知识回看：CPU → [cpu_work](../cpu_work/README.md)，存储介质 → [memory_work](../memory_work/README.md)。
- 本系列通篇**无 OS**——一切都在裸机上。OS 的逻辑在 05 篇末尾自然涌现，然后交给主系列 02-问题暴露与 OS 介入引导。
- 每篇结尾「跨系列对账」负责把零件与整机焊牢。
