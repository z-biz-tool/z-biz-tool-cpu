# mini_machine 04 · 中断与 DMA：解放 CPU

> 03 篇的轮询 echo 把 CPU 100% 烧在 `while(!(SR & RXNE));` 上——为了等一个字节。
> 本篇给机器装上两件解放装置：**中断（外设主动叫人）与 DMA（搬运外包）**。它们也是主系列 01 篇「通道 3：中断、通道 4：DMA」的电路本体。
> **总纲：中断 = 硬件版函数回调；DMA = 硬件版 memcpy；两者合力把 CPU 从搬运工升格为指挥官。**

## 1. 中断控制器 NVIC：总机接线员

Cortex-M 把中断控制器（NVIC）焊在 CPU 核里。每个中断源（外设事件）进来先过它：

```
外设事件线 ──→ [NVIC]
                 │ 每个中断源三个位：
                 │ · ENABLE 使能位（软件决定听谁的）
                 │ · PENDING 挂起位（发生了但还没人管 → 记住）
                 │ · PRIORITY 优先级（同时来多个听谁的）
                 ↓ 仲裁胜出
              CPU 核："放下手头的，跳去处理"
```

- **使能位 = 订阅**：03 篇的外设本身还要再开一次（UART RXNEIEN）——**两级开关：外设愿意说 + NVIC 愿意传**
- **pending 位是关键设计**：你正在处理低优先级中断时又来了一个同级事件——**不会丢**，挂起等处理完再叫；事件可以"排队"
- **优先级**：数字小 = 优先级高；高优先级可打断低优先级的 handler（嵌套）

## 2. 一次中断的完整旅程（硬件到底干了多少活）

按键按下（PA0 上升沿）→ EXTI → NVIC → handler → 返回：

```
1.  引脚电平跳变（GPIO 施密特整形，03 篇）
2.  EXTI 检测到上升沿 → 事件线拉高 → NVIC EXTI0 置 pending
3.  NVIC 仲裁：EXTI0 使能 ∧ 优先级够 ∧ 当前无可抢占者
4.  ★ CPU 硬件自动压栈 8 个寄存器：xPSR, PC, LR, R12, R3, R2, R1, R0
5.  ★ CPU 硬件查向量表：向量表基址 + 中断号×4 → 取 handler 地址 → 写 PC
6.  执行 EXTI0_IRQHandler（软件清 EXTI pending 位，防重复触发）
7.  ★ handler 返回时 LR 里是魔数 EXC_RETURN(0xFFFFFFF9)
    → 硬件识别它 → 自动出栈 8 个寄存器 → PC 回到断点
```

三个★是"硬件包办"的部分：

- **自动压栈**：handler 可以直接用 R0-R3/R12 写 C 函数（编译器按调用约定只用这些）——**中断处理程序的前半段保存现场是硬件免费送的**。对比 RISC-V 裸机中断：要自己写汇编 push 全套寄存器。
- **查表跳转**：向量表是个函数指针数组，**中断号×4 就是下标**——硬件自己算、自己跳，一拍都不用软件插手。
- **EXC_RETURN 魔数**：LR 在进 handler 时被换成特殊值，返回指令见到它就知道"这不是普通函数返回，是中断返回，要出栈恢复现场"。

**嵌套与收尾优化**：高优先级中断可打断低优先级 handler（在更深的栈里再压一层）；连续到来的同级中断走 tail-chaining——省去"出栈又马上入栈"的浪费，直接接下一个 handler。

## 3. 向量表：数组就是调度台

```c
__attribute__((section(".isr_vector")))          // 链接脚本把它放 Flash 开头
const void *vector_table[] = {
    (void*)0x20008000,            // [0] 初始 SP（02 篇：复位第一读）
    Reset_Handler,                // [1] 复位向量（02 篇：复位第二读）
    0, 0, 0,                      // [2..4] NMI/HardFault/…
    0,                            // …
    EXTI0_IRQHandler,             // [16+0] 外设中断从这里开始
    USART2_IRQHandler,            // [16+38] 顺序 = 中断号，一字不差
};
```

- 位置即编号：**USART2 在表里的下标由芯片手册规定**——软件唯一要做的就是"站对位置"
- VTOR 寄存器可把向量表搬到 RAM——运行时换表（bootloader/固件升级的机关）

## 4. 中断版 echo（对比轮询）

```c
volatile char rx_byte;                 // volatile：中断会改它，编译器不知道！
volatile int  rx_flag;

void USART2_IRQHandler(void) {         // 硬件自动跳进来的 C 函数
    if (UART2_SR & (1 << 5)) {         // RXNE?
        rx_byte = UART2_DR;            // 读 DR 顺带清 RXNE
        rx_flag = 1;
    }
}

int main(void) {
    /* …时钟门控/引脚复用/波特率配置…（03 篇） */
    UART2_CR1 |= (1 << 5) | (1 << 13); // RXNEIE: 订阅"收到字节"事件
    NVIC_ISER1 |= (1 << 6);            // NVIC 使能 USART2（38 号）
    for (;;) {
        if (rx_flag) {                 // 主循环只在有事时干活
            while (!(UART2_SR & (1 << 7))) ;
            UART2_DR = rx_byte;
            rx_flag = 0;
        }
        /* …其他工作随时可做，不再被"等字节"卡死… */
    }
}
```

CPU 从"100% 等待"变成"偶尔被打断一下"。两个经典坑直接写进注释：

- **volatile 缺失** → 编译器把 `if (rx_flag)` 优化成读一次的死循环——中断改了它也没人知道
- **临界区**：主循环与 ISR 共享多字节变量时，读一半被中断 → 要 `__disable_irq()/__enable_irq()` 圈起来——**这就是锁的最小硬件形态**（主系列 P2 的雏形）

## 5. DMA：把搬运也外包

中断解决了"要等"，但 UART 收 1KB 仍要中断 1000 次、每次搬 1 字节。DMA（Direct Memory Access）= 总线上另一个 master（01 篇的仲裁埋伏）：

```
             ┌── [DMA 控制器] ──┐
             │  SAR 源地址寄存器  │ ← 软件配：UART DR 地址
             │  DAR 目的地址寄存器│ ← 软件配：内存缓冲区
             │  NDTR 计数寄存器  │ ← 软件配：1024
             │  触发选择        │ ← 软件配：USART2_RXNE
             └─────────────────┘
UART RXNE ──→ 请求 → 仲裁拿总线 → 读 DR → 写内存 → NDTR-1 → 再请求… → NDTR=0 → 传输完成中断
```

一次完整外包后：**1024 字节只产生 1 次中断**（搬运完成），CPU 全程不知情。

- **地址模式**：外设端地址固定（DR 就一个），内存端地址递增、自动重装/循环模式（环形缓冲白送）
- **与 CPU 抢总线**（01 篇仲裁回扣）：DMA 拆 burst 偷缝，CPU 最多慢几拍；高优先 DMA 通道先走
- **代价与纪律**：CPU 与 DMA 同时读写同一块内存 = 裸机上最朴素的缓存一致性问题；DMA 写内存前要保证 cache 无脏副本（M7 有 cache 的核要 invalidate）——**多 master 的第一课，提前预演主系列多核同步**

## 6. 中断 + DMA 合体后的软件形态

轮询 → 中断 → DMA 的三级解放，正好对应驱动程序的进化史：

| 阶段 | CPU 占用 | 典型场景 |
|---|---|---|
| 轮询 | 100% 空转 | 玩具程序、上电早期的轮询调试输出 |
| 中断 | 每事件几 μs | 低速率外设（按键、慢串口） |
| 中断+DMA | 每缓冲 1 次中断 | 高吞吐（音频流、网络、SD 卡） |

Linux 驱动模型（request_irq + dmaengine）就是这个表在大机器上的翻版——**形式没变，只是规模变了**。

## 7. 本篇结论

1. **NVIC 三件套**（使能/挂起/优先级）+ 两级订阅 = 中断世界的全部秩序；pending 位保证事件不丢。
2. 一次中断旅程的三个硬件包办：自动压栈、查表跳转、EXC_RETURN 魔数——**C 语言能直接写 ISR 全靠它们**。
3. 向量表是"位置即编号"的函数指针数组——主系列 01 篇"通道 3 门铃"的真实电路。
4. volatile 与临界区是裸机并发的第一课：中断是异步的、编译器是同步视角的、两者必须显式和解。
5. **DMA = 可编程搬运协处理器**（SAR/DAR/NDTR/触发源四寄存器），与 CPU 靠总线仲裁共存；同内存并行读写出一致性问题的第一课。
6. 轮询/中断/DMA 三级解放对应驱动进化史；CPU 的角色从搬运工变成指挥官——**这个转变就是一切驱动模型的根**。
