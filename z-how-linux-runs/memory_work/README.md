# memory_work · 存储是怎么把"记性"卖给你的

[cpu_work](../cpu_work/README.md) 讲完了"算"——但 CPU 六篇的结尾（内存墙、缓存层级）早就剧透：**算得再快，数据的真身都在"记"那边。** 本系列把存储拆开：DRAM 为什么必须刷新、SSD 为什么要造假、磁盘为什么顺序比随机快一千倍——各种存储介质的本质、逻辑与运行原理。

方法论不变：归约法。存储的一切怪癖（刷新、先擦后写、寻道时间）都能归约到一个物理问题：**凭什么一个状态能持续存在？**

## 主线（整条逻辑链，一图流）

```
存储的本质       → 让一个状态持续存在（三种维持机制）
易失分水岭       → 靠供电维持 = 易失；物理态自持 = 非易失
SRAM             → 6 管双稳态：cpu_work 04 的触发器，快、贵、不刷新
DRAM             → 1 管 1 电容：漏电 → 刷新；读是破坏性的；按行激活
DDR 与控制器     → 时序参数 = 物理动作说明书；bank/rank/channel；内存墙真相
浮栅晶体管       → 把电子关进绝缘层牢房：ROM→EPROM→EEPROM→Flash
NOR vs NAND      → 随机读 vs 按页读；擦必须整块；P/E 磨损；SLC→QLC
SSD = FTL        → 盒子里的迷你计算机：映射表、写放大、GC、TRIM
磁存储           → 磁化方向；机械臂延迟解剖；顺序/随机鸿沟 1000 倍
存储金字塔       → 速度/容量/价格三角，必然分层
与 OS 连接       → page cache/swap/NUMA/CXL——三层栈重复实现同一套缓存
```

一个总纲、五个分水岭：

| 节点 | 意义 |
|---|---|
| **维持机制三分**（00 篇） | 双稳态（要电）/ 电荷囚禁（看绝缘层厚度）/ 物理相·磁化（自持）——一张表解释所有介质的易失性 |
| **破坏性读**（00/01 篇） | 读 = 测量，测量会扰动状态——DRAM 读后自动回写、Flash 读干扰的根源 |
| **行激活**（01 篇） | DRAM 的一切时序怪癖 = "先搬一整行进缓冲区"这一个动作 |
| **先擦后写**（02 篇） | Flash 不能原地改写 → 逼出 FTL → SSD 变成一台迷你计算机（03 篇） |
| **物理位置 = 时间**（04 篇） | 磁盘的延迟解剖；顺序/随机鸿沟是机械的，软件只能适应 |

## 与 cpu_work 的对账

- **SRAM = cpu_work 04 篇的双稳态回路**：寄存器堆、L1-L3 缓存、TLB 全是它（01 篇）
- **DRAM 的译码器** = cpu_work 05 篇"按地址点名"的行选择（01 篇）
- **内存墙**（cpu_work 06 P4）在本系列 01/05 篇给出完整物理解释
- **FTL ≈ MMU**：SSD 的逻辑块映射和主系列 04 篇的页表同构（03 篇）
- **page cache / swap** = 金字塔上下的搬运，主系列 02 篇"常驻公共代码"的存储版（05 篇）
