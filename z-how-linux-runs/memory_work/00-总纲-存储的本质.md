# memory_work 00 · 总纲：存储的本质（彻底版）

> cpu_work 造出了"算"，本系列拆"记"。
> 开篇先立总纲：**存储 = 维持一个状态**。本篇把这句话拆到物理层：什么算"状态"、靠什么维持、读它为什么有代价、写它为什么更贵——一张底牌解释后面每一篇介质。

## 1. 什么算"状态"：存储的最小定义

先做减法。一台 1TB 硬盘、一颗 8Gb DRAM 芯片、一张磁带，共同点是什么？

**它们都在回答同一个问题：此刻是 0 还是 1？** 而"此刻"是关键词——不是"刚才"，不是"曾经"，是这个瞬间。

- 一个粒子可以"记得"自己的位置（物理态自持）
- 一个电路可以"记得"自己的电压（正反馈锁定）
- 一颗电容可以"记得"自己有没有电荷（电荷囚禁）

存储的最小定义：**一个能稳定停留在有限个状态之一、且状态可被外部询问的物理系统**。三个要素缺一不可：稳定（不自己漂移）、有限（状态数确定，二进制就是 2 个）、可询问（读得出）。

## 2. 三种维持机制：全部介质的底牌

| 机制 | 电路/物理实现 | 代表介质 | 维持要什么 | 易失性 |
|---|---|---|---|---|
| ① 正反馈锁定 | 两个反相器互相咬尾（cpu_work 04 双稳态） | SRAM、寄存器、触发器 | **持续供电**（锁门的人要一直醒着） | 易失 |
| ② 电荷囚禁 | 电容/浮栅 + 高墙（绝缘层） | DRAM、Flash | ①式要电；②式只看**墙够不够厚** | DRAM 易失（墙薄）；Flash 非易失（墙厚） |
| ③ 物理态自持 | 原子自己排好队 | 磁化（HDD/磁带）、相变、坑平（CD） | **不吃饭**——原子自发排列，宇宙射线都懒得动它 | 非易失 |

每种机制展开一句：

- **①正反馈锁定**：反相器 A 出 1 喂给 B，B 出 0 喂回 A——环上任何偏移都被放大推回原位。代价：这套"看门的"时刻在耗电，且断电即忘——**锁住的是电平，不是电子本身**。
- **②电荷囚禁**：把电子关进绝缘层围成的牢房。DRAM 的牢房是电容（细高的塔，30fF），门薄（几 nm）——**囚禁要满 64ms 刷新**；Flash 的牢房是浮栅（氧化层 10nm+），门厚到电子靠隧穿才能进出——**关得住 10 年**。同一种机制的墙厚版本。
- **③物理态自持**：磁化方向、原子晶格位置，是材料自身的能量极小态——**没有外力它不挪窝**。磁带 50 年、硬盘 10 年、CD 百年——都靠原子"躺平"。但正因为状态"躺平"在物理材料上，读写它必须动用宏观机构（磁头、激光）——**快不起来**。

**读这张表就能预测后面每一篇**：SRAM 为什么快（机制①电平直接进逻辑）、DRAM 为什么要刷新（机制②墙薄）、Flash 为什么擦块（机制②改一个牢房要动一片墙）、HDD 为什么慢（机制③要机械臂）——**快慢易失的取舍全部来自"维持机制"这一个选择**。

## 3. 读 = 测量即扰动

量子力学的破坏性测量在存储里是日常：**读一个状态，常常会破坏它**。三类介质各有一例：

| 介质 | 破坏方式 | 补救 |
|---|---|---|
| DRAM | 电荷共享把 cell 电荷分给位线，读后剩一半（memory_work 01 §2.3 算过：ΔV≈54mV） | 感放放大回写——读即刷新 |
| Flash（NOR 读） | 高压/电子应力累积，读取本身轻微磨损氧化层（读打扰 read disturb） | 读耐受 10⁵~10⁶ 次，一般无感 |
| 磁读出 | 早期磁芯存储器：读脉冲直接把磁化翻转掉（ destructive read） | 读后必须立即回写——磁芯时代每读一次是"读+写"两拍 |

磁芯的例子值得记住：**1950-70 年代主存（"core memory"，至今英语里"内存快照"还叫 core dump）每读一个 bit 都要回写**——DRAM 的感放回写不是新发明，是 70 年前的老规矩换了个电路。

## 4. 写的代价不对称

读是"看一眼"，写是"改世界"——**改总比看贵**，且贵多少取决于维持机制：

- **SRAM**：写 ≈ 读（都是位线电平操作）——不对称最弱
- **DRAM**：写 = 一次行激活 + 电荷注入 ≈ 读的量级——轻度不对称
- **Flash**：**重写必须先擦除整块**（把整个牢房区清空才能重新关人）——擦块 4~64KB、耗时 1~10ms，比读页（~100μs）慢 10~100 倍。**"先擦后写"是 Flash 一切怪癖的根**（02/03 篇展开：FTL、写放大、GC 全从这里长出来）
- **HDD**：随机写 = 重新寻道+等旋转——比读同地段还慢一点点（读可以慢慢扫，写必须精确落点再校验）

**一条通用规律：写比读贵，且"改写已有内容"比"追加新的"更贵**——所以上层软件的设计都在绕这个不对称：日志文件系统只追加、SSD 内部只写新位置、数据库的 WAL 只增不改。**存储介质的不对称形状，直接塑造了上面全部软件的形状。**

## 5. 三问定座次

给任何介质三个问题，就能推演它的全部工程属性：

1. **维持靠什么？**（电 / 墙厚 / 原子）→ 定易失性与数据寿命
2. **读要扰动吗？扰动多大？** → 定读速度与是否要回写
3. **写的最小单位是什么？改写要什么代价？** → 定写速度、寿命与上层软件形态

| 介质 | 1.维持 | 2.读 | 3.写 |
|---|---|---|---|
| SRAM | 供电 + 正反馈 | 无损、~1ns | ≈读，按位 |
| DRAM | 供电 + 64ms 刷新 | 破坏性（回写） | ≈读，按位 |
| Flash | 浮栅墙厚 | 无损、~100μs | **先擦整块（1-10ms）再写页（~1ms）** |
| HDD/磁带 | 原子磁化 | 机械移动（ms 级） | 同样机械移动，可原地覆写 |
| 相变/光盘 | 晶态/坑洞 | 光学读 | 相变要脉冲加热 / 光盘一次写 |

## 6. 本篇结论

1. **存储 = 维持一个可询问的稳定状态**——三要素：稳定、有限、可读。
2. 全部介质归于三种维持机制：正反馈锁定、电荷囚禁（墙厚版本）、物理态自持——**机制决定快慢与易失**。
3. 读常常是破坏性的，读后回写是老规矩（磁芯 70 年前就这么干）。
4. **写比读贵、改写比追加贵**——介质的不对称形状塑造了其上全部软件的形状（日志/FTL/WAL 都是绕不对称的手段）。
5. 三问（维持/读扰动/写单位）可以推演任何介质——后面每篇都先用这三问开拆。
