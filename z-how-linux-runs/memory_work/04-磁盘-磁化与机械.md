# memory_work 04 · 磁盘：磁化与机械（彻底版）

> 最古老的介质活到今天的完整解剖：从磁滞回线的物理，到 1nm 飞高的磁头、伺服闭环、μV 级信号链、13ms 延迟的逐段账单、SMART 每个编号的含义。
> 一句话总纲：**在 HDD 上，物理位置 = 时间；本篇解释为什么、慢在哪、以及全行业如何绕。**

## 1. 磁记录的物理基础

### 1.1 磁滞回线：状态为什么"站得住"

铁磁材料的 B-H 曲线是"记忆"二字的物理定义：

```
B（磁通密度）
 │      ↗ 剩磁 Br ←────────
 │     ╱╱                ╲╲
────┼──────────────────────── H（外加磁场）
 │  ╲╲                ╱╱
 │  ←──────── ↘ -Br
 │        -Hc      +Hc（矫顽力）
```

- 外磁场撤掉后，材料**停在剩磁 Br**（不是回原点）——这就是"记得住"：00 篇机制③，原子的自发排列
- 要改写必须外加超过**矫顽力 Hc** 的反向磁场——这就是"改不掉"：普通杂散磁场远小于 Hc，数据天然抗噪
- **两个参数的权衡定生死**：Hc 高 → 稳定 → 但难写；Hc 低 → 好写 → 热扰动就翻转。介质工程的全部游戏 = 找到骑线点的材料

### 1.2 一粒 grain ≠ 一个 bit：颗粒与信噪比

1 bit 由**几十到上百个磁晶粒（grain）**组成，读出信号是它们的平均——grain 越多信噪比越高，但 bit 就越大；密度进化的路线 = grain 变小 + bit 用更少 grain（现在是 ~20 粒）。grain 的尺寸分布、随机取向造成**写错/读抖动的本底噪声**——每代密度升级都要在材料上打赢一次信噪比战。

### 1.3 超顺磁极限：密度的物理天花板与 HAMR

grain 小到一定程度，热能 kT 就能自发改写磁化（超顺磁效应）——数据自己化掉。判据：**热稳定比 KuV/kT ≥ 60**（V=grain 体积，K=各向异性能量密度）。出路两条：

- **提高 K**：铁铂合金（FePt）Hc 极高——但写不动了
- **HAMR（热辅助磁记录）**：写头自带激光器，写的那 1 ns 把介质**加热到居里点附近**（Hc 骤降），磁头轻松写入，冷却后稳如磐石——**"先软化再落笔"**，2023 起商用（Seagate 30TB+）。物理约束 → 加一个激光器绕过去

### 1.4 LMR → PMR：为什么躺不行要立

水平磁化（LMR）相邻 bit 磁场同性相斥（退磁场），密度越高越自毁。**垂直磁化（PMR）**：磁化方向垂直盘面 + 底下垫一层软磁底层（SUL）把磁通回路封闭——退磁场变助力，密度 ×3 以上。00 篇说的"原子躺平"要改成"原子立正"，才有了今天的 TB 级。

## 2. 盘片：多层三明治

一块 2.5/3.5 英寸盘片（铝镁合金或玻璃基板——玻璃更平、更耐摔，笔记本盘用）从下到上：

1. 基板：纳米级抛光（表面粗糙度 <0.5nm）
2. **软磁底层 SUL**（PMR）：写头磁通的"回路导体"
3. 磁记录层：CoCrPt 系合金，溅射沉积，grain 尺寸 ~7nm
4. 类金刚石保护层（DLC）：~2nm，抗磁头微碰撞
5. 润滑层：~1nm 全氟聚醚，磁头意外触地时不粘死

**整块"记录层"总厚度 <30nm**——一块硬盘的核心科技是一层比保鲜膜薄十万分之一的薄膜。

## 3. 磁头：人类制造的最小飞行器

### 3.1 结构：写头与读头是两个器件

- **写头**：微型电磁铁——1~2 匝线圈的平面线圈，电流反向 → 磁通经磁极尖端聚焦到 ~50nm 磁道宽，翻转下方磁畴
- **读头**：**TMR 隧穿磁阻结**——两层铁磁层夹 1nm MgO 绝缘层，电子量子隧穿；下层磁化方向被"钉死"，上层随盘面磁化摆动 → 电阻变化 %级，μA 电流读出 μV 级信号。（GMR 是它的前辈：2007 诺贝尔奖；TMR 灵敏度更高，2006 起普及。**一块几百块的硬盘里含着诺奖级器件**。）

### 3.2 飞行：1-2nm 高度上的气垫

磁头不接触盘面，**飞高 1-2nm**（盘面凸起都比它高）——靠**气垫面（ABS，Air Bearing Surface）**：磁头滑块底面精雕的阶台形状，盘片 7200rpm 携带气流把滑块托起（伯努利/动压气垫），自稳闭环：飞高自动调节。

- 比例感：飞高 2nm 相当于波音 787 贴地飞行 0.4mm——还是"贴着地皮的气垫船"
- **氦气封装**（Helium，2013+）：氦密度为空气 1/7 → 湍流/抖动减半 → 盘片可以贴更近、叠 9~10 片、功耗降 ~30%、更安静。**十片盘片一颗氦蛋**
- 磁头起降：停机时磁头**移出盘面落到 ramp（斜坡停机坪）**（load/unload 设计，60 万次起降规格）；老式 CSS 设计是降落在专用着陆区拖行——现在绝迹

## 4. 信号链：从 μV 到比特

读出信号只有几百 μV 且被噪声糊住。完整链：

```
磁头 TMR 电阻变化 → 前置放大（盘内 IC）→ 可变增益放大
 → 滤波均衡 → PRML 检测 → 位流 → EDC/ECC 校验 → 缓存 → 接口
```

- **磁记录不直接写"0/1 电平"，写的是磁通翻转（NRZI 类）**：翻转=1，不翻转=0——同步时钟靠翻转密度规则保证
- **RLL(d,k) 编码**：约束"1 至少隔 d 位、至多连 k 位"——太密读不清（脉冲挤叠），太稀丢时钟；经典 2,7 码、现代 PRML 配合高密度
- **PRML（部分响应最大似然）**：高密度下脉冲互相重叠（部分响应），不再判"每个点是什么"，而是用**维特比算法对整段波形序列找最可能的 bit 序列**——通信 DSP 技术直接移植进盘固件，是 90 年代密度翻番的功臣
- **错误率预算**：原始误码率 ~1e-6 → 每扇区附 ~100+ 字节 ECC（RS 码/LDPC）→ 修复后端到端 1e-15 以下；读不出 → 重试 → 重映射（见第 8 节）

## 5. 伺服与定位：磁道是怎么"找到"的

磁头是个自由飞行的东西，它**怎么知道自己压没压准磁道**？

### 5.1 嵌入式伺服

盘面上每条磁道被切成几百个**伺服楔（servo wedge）**——楔内不是数据，是工厂预写的**位置信息**（一条专用磁道脉冲 + 格雷码磁道号）。磁头每转过一个楔就读一次"我在哪、偏了多少"，每转采样 ~几百次。**数据与路标同盘共存，路标是出厂激光/磁写死的，永久不可改**（这也是"低级格式化"的现代含义）。

### 5.2 音圈电机的两级闭环

音圈电机（VCM）是钕磁铁间的线圈摆臂（就是"电机"倒过来的用法）：

- **寻道模式（速度环）**：全电流加速 → 按距离规划的速度曲线滑行 → 反向制动——像狙击手先甩枪
- **跟踪模式（位置环）**：到位后切 PES（位置误差信号）闭环，磁头微颤锁定磁道中心，**settle ~0.5ms**
- 冷热形变、盘片锥形摆（盘高速旋转的伞状微变形）都靠伺服实时补偿；写后立即回读校验（write verify）抓"写歪"

## 6. 13ms 延迟的逐段账单（一次随机读的全旅程）

```
OS 发 read(LBA) → SATA 控制器 → 盘内 NCQ 队列
  → [固件调度 ~0.05-1ms：可能重排顺序、等缓存状态]
  → 寻道 4-9ms（行程越远越贵：1/3 冲程 ~4ms，全冲程 ~12ms）
  → settle 0.5ms
  → 旋转等待 0-8.33ms（平均半圈 4.17ms @7200rpm）
  → 读扇区 + PRML + ECC 0.1-0.5ms
  → 盘载缓存 → SATA 6Gbps 传输 4KB ≈ 6μs
合计 ~9-14ms
```

- **IOPS ≈ 1/13ms ≈ 75-150**；顺序读（同磁道连片）消掉寻道+旋转 → 200-280 MB/s
- **顺序/随机鸿沟 ~1000 倍，全部是磁头移动与等待**——"地址即时间"的完整账单
- 盘内缓存（32-256MB DRAM）：读预取（多吞几道）+ 写回缓存（write cache：主机"写完成"其实是进了盘缓存——掉电窗口存在，数据库都强制 write-through/fsync 场景要关写缓存的原因）

### NCQ：电梯算法住在盘里

SATA NCQ 允许 OS 一次挂 32 条命令，**盘固件按当前磁头位置重排执行顺序**（最短寻道优先 NPVA）——OS 的电梯算法其实下沉到了盘内（第 4 节说 OS 的电梯是给旧设备用的；现代 HDD 的调度在固件里）。

## 7. 几何与寻址的进化

- **ZBR（等角速度位密度）**：盘恒转速 → 外圈线速度快 → 外圈磁道容纳更多扇区（内圈 700 扇区/道，外圈 ~2000）→ **同一块盘外圈比内圈快 ~2 倍**——分区/基准测试里"外圈速度"玄学的出处
- **CHS → LBA**：早期 OS 要知道 柱面/磁头/扇区三维坐标；LBA 把全盘扇区线性编号，盘内固件翻译（**FTL 的祖师爷**，03 篇）
- **512e vs 4Kn**：物理扇区 4KB（ECC 更强、格式效率高），但兼容层可以假装 512B（512e）——**错位写入（不按 4K 对齐）会触发读-改-写**，掉性能；高级格式化/分区对齐 1MB 就是这个历史
- **SMR 叠瓦**：磁道重叠 10~20% 提密度，改写一条要连带重写后面一串 → 盘内一层 zone FTL；随机写灾难（详见 memory_work 03 篇同款机制）——买盘认 CMR

## 8. 坏道与可靠性管理

### 8.1 坏块重映射：出厂就开始的偷梁换柱

- **P-list（工厂缺陷表）**：出厂测试发现的坏扇区，出厂即用备用扇区替换（用户永远看不到）
- **G-list（增长缺陷表）**：运行中扇区劣化 → 固件自动把数据搬到备用扇区、重映射 LBA；少量重映射是正常老化，**快速增长 = 盘要死了**
- 每个盘留几千个备用扇区；备用扇区用尽 → 数据丢失

### 8.2 SMART：盘的自我坦白书

| ID | 属性 | 含义 | 危险信号 |
|---|---|---|---|
| 05 | Reallocated Sectors | 已重映射扇区数 | **持续增长 = 换盘** |
| C5 (197) | Pending Sectors | 疑似坏、待处理 | 非零且增长 = 危 |
| C6 (198) | Uncorrectable | ECC 也救不回的 | 非零 = 数据已丢 |
| 01/07 | 读/寻道错误率 | 磁头/介质健康趋势 | 缓慢增长可容忍 |
| C7 | UDMA CRC 错 | **线缆/接口问题**（不是盘坏！） | 换线换槽 |

（`smartctl -a` 直接读——这块表就是盘的体检报告，看盘先看 05/C5/C6。）

### 8.3 寿命数字

- 年化故障率 AFR：企业盘标 0.35%~0.8%（Google/Backblaze 实测 ~1.5%，前三个月与三年后是死亡高峰——浴盆曲线）
- 负载循环：磁头起降 60 万次；年通电 8760h（企业级）vs 2400h（桌面级规格）
- 振动：多盘机箱共振 → 磁头写偏 → **企业盘带 RV 旋转振动传感器**；"机箱里多插几块盘变慢/报错"常是振动问题

## 9. 接口与电气

- **SATA**：数据 7pin（差分对）+ 供电 15pin；6Gbps 上限 ~550MB/s；NCQ 32 深
- **SAS**（企业）：全双工、12/24Gbps、双端口冗余路径（一根线坏了另一根顶）、可扩展 expander 接上百盘
- **启动电流**：主轴电机启动瞬间 ~2A（1.5-3A，持续 ~10s）——十几块盘同时启转会顶跳闸 → 机箱做 staggered spin-up（错峰上电）
- **双臂 MACH.2**：一块盘两个磁头臂 = 双倍 IOPS（希捷 Exos 2X14）——机械并行的极限尝试

## 10. RAID 速补（详见本篇旧版与本系列 05 篇）

RAID 1/5/6 的异或校验、重建风险、以及"重建中再坏一块"的概率随盘容量增长而上升——大盘时代 RAID 5 已死，RAID 6/三副本/纠删码上位。

## 11. 为什么 HDD 活到今天

- **$/TB 仍是 SSD 的 1/5~1/10**：30TB 盘 vs 30TB SSD 价格差一个数量级
- 云厂冷存储（照片、备份、视频库）是它的天下：近线 helium 盘阵列 + 纠删码
- 进化仍未停：HAMR 40TB+、氦气 10 盘片、双臂——**"最古老"不等于"停止进化"**
- 与 03 篇互为镜像：SSD 赢了延迟，HDD 赢了每 GB；Optane 死于两边都没占到（物理全胜、价格全败）

## 12. 本篇结论

1. **磁滞回线定义了"记得住 + 改不掉"**：剩磁与矫顽力是存储的物理合约；超顺磁极限是密度的天花板，HAMR 用"加热落笔"绕行。
2. **磁头是人类最小飞行器**：1-2nm 气垫飞行 + TMR 隧穿读出 + 氦气封装——一块盘里压着诺奖器件与航空级表面工程。
3. **信号链是通信工程**：RLL 编码、PRML 维特比、ECC 预算——磁盘的一半是 DSP。
4. **定位是闭环控制**：嵌入式伺服楔 + 音圈电机速度/位置双环——"找到磁道"是个控制论问题。
5. **13ms 的每一 μs 都有归属**：调度在盘内（NCQ/NPVA）、缓存有掉电窗口、SMART 是体检表、坏道重映射从出厂就开始。
6. **HDD 不死因为 $/TB**；它与 SSD 的分界线由经济学画，不由物理学画。
