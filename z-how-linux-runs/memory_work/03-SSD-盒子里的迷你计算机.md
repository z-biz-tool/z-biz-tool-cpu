# memory_work 03 · SSD：盒子里的迷你计算机（彻底版）

> 02 篇的三条铁律（擦块、顺序写、寿命配额）与 OS 的期望（随机写、原地改、无限寿命）正面冲突。
> SSD 的答案是往盒子里塞一台迷你计算机（FTL 固件 + DRAM + 电容）。本篇把这台迷你计算机拆透。
> **一句话总纲：SSD = 用一层软件（FTL）把 NAND 的物理铁律翻译成磁盘的道德习惯——这层翻译是它快、也是它所有坑的来源。**

## 1. 冲突现场：OS 的期望 vs NAND 的铁律

| OS/文件系统期望 | NAND 物理现实（02 篇） | 冲突 |
|---|---|---|
| 扇区/LBA 线性地址，随便覆盖写 | 页 16KB 只能按序写、写过不能重写 | **改一个扇区 = 不可能原地完成** |
| 写任意位置代价相同 | 擦除按块（6MB），改 1 字节理论上要搬 6MB | **随机写是天灾** |
| 无限次写 | TLC ~3000 次 P/E | **寿命要精打细算** |
| 坏扇区报给我，我来管 | 坏块不断涌现，需要实时管理 | **磨损管理是全职工作** |

处理这种冲突的标准硬件答案：**翻译层**。CPU 侧早有先例——MMU 把虚拟地址翻译成物理地址（02 主系列 P3）。SSD 把同一招搬进盒子：

## 2. FTL：SSD 里的 MMU（同构到惊人）

```
OS 发 LBA 1000 → FTL 查映射表 → PPA 77777（物理页）→ NAND 实际位置
OS 覆写 LBA 1000 → FTL 不改原页！→ 找空页 88888 写入 → 更新映射：1000→88888
                                              （旧页 77777 变"僵尸"，等 GC 回收）
```

与 MMU 的对应关系逐项成立：

| | MMU（CPU） | FTL（SSD） |
|---|---|---|
| 翻译对象 | 虚拟页 → 物理帧 | LBA（逻辑块）→ PPA（物理页） |
| 表存哪 | 内存页表 | SSD 内 DRAM 的映射表 |
| 写时复制 | COW（fork 时） | **所有写都是 COW**（NAND 逼的） |
| 回收 | 页面换出/释放 | GC（§3） |
| 表太大怎么办 | 多级页表 | 混合映射（块级+页级，见下） |
| 单点风险 | 内核错表 = 系统崩 | **映射表丢 = 全盘数据丢**（它才是 SSD 的命根子） |

映射表多大？1TB SSD、4KB LBA → 2.5 亿条目 × 4 字节 = **1GB DRAM**——所以 SSD 盒子里真有一颗 DRAM 颗粒，它的主要工作就是这张表（无 DRAM 方案用页内表+闪存缓存，慢些）。

映射粒度的取舍：**页级映射**（每 4KB 一条，1GB 表，任意写完美）vs **块级映射**（每 6MB 一条，几 MB 表，但块内偏移重写要搬整块）→ 真实 FTL 用**混合**：日志式追加写页级映射 + 随机小写聚批。**这层取舍直接决定随机写性能**。

## 3. 写放大与 GC：搬家经济学

写放大（Write Amplification, WA）= 实际写进 NAND 的量 ÷ OS 以为写出的量。看一个最小演算：

```
块 6MB = 384 页。已写满且全是"活"数据 + 8 个僵尸页（OS 覆盖过 8 次）
要腾 16KB 空间？→ 整块擦除前必须先把 376 个活页搬走：
实际写入 NAND：376 页搬运 + 1 页新数据 = 377 页
OS 只写了：1 页
WA = 377
```

GC（垃圾回收）就是批量做这件事：攒几个块，把活数据集中搬到新块，旧块整块擦除回池。**WA 越高：寿命消耗越快（P/E 配额照搬的量扣）+ 写入越慢**。

控制 WA 的三板斧：

1. **TRIM（核心）**：OS `rm` 一个文件后，文件系统对 SSD 说"这些 LBA 我不要了"（`fstrim`/discard 命令）。FTL 把对应页标记为僵尸——**GC 时不用再搬它们**，WA 立降。没有 TRIM 的系统（老 OS、RAID 阵列层），SSD 以为全盘都是活数据，越用越慢——**这就是"SSD 用一段时间变卡"的头号原因**。
2. **OP（预留空间）**：盘容量故意比 NAND 物理容量小——
   - 512GB 盘实际焊 576GB NAND（OP = 12.5%）
   - OP 越大，FTL 挪活数据时可挑选的空页越多、GC 效率越高、WA 越低
   - 数字账：WA ≈ 1/(1−无效页比例)。OP 7%（企业 28%）→ GC 时刻总有富余
3. **磨损均衡（wear leveling）**：只把热数据写在少数块上，那些块几千次就磨穿。FTL 的动态均衡让**每个块轮流承担写入**——"不动"的冷数据也会被 GC 搬家（**静态磨损均衡：搬冷数据不是为了腾空间，是为了给它们所在块放假**）。00 篇"不动也是动作"的出处。

## 4. SLC cache：为什么新盘"跑分吓人，用着用着变慢"

TLC 页写 ~1ms，但 SSD 跑分能冲 3GB/s？——**盘里留一块 NAND 冒充 SLC 用**：

- 一部分 TLC 块**只写低档位（当 SLC）**：每单元只关 1 档电子，写速接近 SLC（~200μs/页）
- OS 写入先落这块"SLC cache"（可达几十 GB）→ 跑分/日常突发写极快
- 闲时 FTL 后台把 cache 里的数据**重新按 TLC 编程**（多轮高压精确关档）搬进正区——这个过程叫 folding，占用的正是 GC 带宽
- 一次性写超 cache 容量（比如拷 100GB）→ 直接落 TLC 速度，**掉速到 500MB/s 级**——不是坏，是"高速假象"的物理上限到了

**SLC cache 大小随剩余空间变化**：盘越满，可冒充 SLC 的块越少（它们本质是"尚未二段编程的空块"）——所以**满盘的 SSD 掉速是双重叠加**（GC 压力 + cache 缩水）。

## 5. 掉电保护：映射表不能死

FTL 的命根子是映射表（§2），但它常驻 DRAM——**掉电即失**。断电瞬间 OS 有几百 MB"以为写完了"的数据在盘里乱序分布。SSD 的自救：

- **PLP（Power Loss Protection，企业盘标配）**：盒内钽电容组，掉电时供最后 ~20ms 电——把 DRAM 里的映射变更 journal 刷进 NAND 固定区
- 消费盘无 PLP → 固件必须保证映射表**每次更新都先落 NAND**（日志式映射更新）→ 上电时重放日志重建映射——**一个盒子里塞了一台小型日志文件系统**
- "写完返回但没真写"的窗口：消费盘可能丢最近几百 ms 数据；企业盘靠 PLP + 全盘电容保证"返回即落盘"——**数据库敢不敢放 SSD 上，看的就是这个**

## 6. NVMe：为闪存重造的接口

SATA 是给机械盘设计的（磁头一次伺候一个请求）：1 条队列、深 32、6Gbps 顶死 ~550MB/s。NAND 并行度是 die×plane×block 级——**喂不饱**。

NVMe 直连 PCIe：

| | SATA | NVMe |
|---|---|---|
| 队列 | 1 条 × 32 深 | **65535 条 × 65535 深**（每核一队列，免锁） |
| 延迟 | ~100μs（协议开销占比高） | ~10-20μs |
| 带宽 | 550MB/s | 3.5/7/14 GB/s（PCIe 3/4/5 ×4） |
| 提交机制 | 寄存器轮询 | **doorbell 寄存器 + 内存队列**（01 篇 MMIO：写一个 doorbell 就是提交一批命令） |

队列对的机制：提交队列 SQ（OS 写命令）+ 完成队列 CQ（盘写结果）+ doorbell（OS 敲一下告诉盘"SQ 有新货"）。**多核各用各的队列 → 多核并行写盘互不抢锁**——接口设计与缓存一致性（cpu_work 06 MESI）是同一个问题的两个侧面。

## 7. 产业注脚：Optane 之死

Intel/Micron 的 3D XPoint（Optane，2017-2022）：相变材料，按字节寻址、延迟 ~300ns（比 NAND 快 100 倍）、无限寿命、非易失——**物理上全面胜出**。

死于经济学：量产成本降不下来（专用产线、专用控制器），售价是 NAND 的 5-10 倍；DRAM 降价后它的"内存扩展"位被 CXL 抢走。**2022 年全线停产。**

教训与 04 篇呼应：**存储技术的生死由 $/GB×延迟曲线的中间地带决定，不是由物理极限决定**——打得过 NAND 的延迟、打不过 NAND 的价格，就是死。

## 8. 本篇结论

1. **SSD = FTL（翻译）+ DRAM（映射表）+ 电容（掉电保命）**——一台迷你计算机，职责是把 NAND 铁律翻译成 OS 期望。
2. FTL 与 MMU 同构：COW、映射、回收、多级/混合表——**虚拟化思想在盒子里的重演**。
3. WA/GC/TRIM/OP 是一组联动的搬家经济学：TRIM 告诉 GC 谁不用搬、OP 给 GC 留机动空间、磨损均衡让"不动"也动。
4. SLC cache 解释"前快后慢"；满盘掉速是 GC 压力 + cache 缩水双重叠加。
5. NVMe 用多队列把并行度从接口层喂给 NAND——SATA 的单队列是磁头时代的遗产。
6. Optane 物理全胜、价格全败——**介质替代的裁判是经济学**（04 篇 HDD 不死的镜像）。
