# Linux 是怎么执行的

用「先根能力，再设计」的方法重读《Linux 是怎么工作的》。

## 方法论：归约法

遇到任何 OS 概念，不断追问「它最终归结为哪几条根能力（哪条指令）」，直到归约到底：

- 归约到底了 → 真正理解了
- 中途卡住、发现某步"凭什么是这样" → 那里就是要细读的地方

### 根能力清单（硬件给的，全部就这些）

| 域 | 根能力 |
|---|---|
| CPU | 取指-执行循环；`syscall`/`sysret`；中断/`iret`；`cli`/`sti`/`hlt` |
| 内存 | `mov` 读写；`mov CR3`（切地址空间）；`invlpg`（刷 TLB）；MMU 自动翻译 + 缺页异常钩子 |
| 多核同步 | `lock xchg` / `lock cmpxchg`；内存屏障 |
| 设备 | `out`/`in` 或 MMIO（本质都是读写地址）；中断；DMA |

其余一切（进程、文件、锁、调度算法、伙伴系统……）都是用这些原子方法搭出来的**设计**，不是根能力。
