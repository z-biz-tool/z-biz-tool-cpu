# cpu_work · CPU 是怎么从沙子里长出来的

主系列的 [01-硬件规约](../01-硬件规约.md) 开篇就说"CPU 是一个死循环执行器"——但把它当成黑盒。本系列把这个黑盒拆开：**那个死循环本身，是怎么从一撮沙子（硅）一步步长出来的。**

方法论不变：归约法。不断追问"它归结为哪几条根能力"，只不过这次归约的方向是**向下**——从指令归约到电路，从电路归约到物理。

结构：**一篇前传 + 六篇主线**。主线只讲最短路径，但每篇内嵌"进化点"小节——继电器与真空管、BJT 与 TTL 的内战、JK 触发器、亚稳态、总线与三态门、微程序与硬连线之争、功耗墙……这些是真实历史里差点改变走向的岔路，不能让主线"太顺"（索引见下）。

## 主线（整条逻辑链，一图流）

```
（前传）继电器→真空管→晶体管；二进制的胜出；存储程序 1945；光刻
硅 + 掺杂          → N 型 / P 型半导体
PN 结              → 单向阀（二极管）
BJT/TTL 内战       → 功耗决定胜负，CMOS 上位
受控开关           → 晶体管（MOSFET）
符号代替           → 逻辑门（0/1 + 布尔代数），可无限级联
门搭组合逻辑       → 加法器 / 译码器 / MUX（算，但没记性）
×意外的回路×       → 锁存器 / 触发器（会记了！）
JK→T→计数器       → 缺陷态变功能，电路会数数
时钟统一节拍       → 时序逻辑（状态机）
译码器选电路       → 控制器 + 数据通路 = 单周期 CPU
总线/微程序/中断   → 三态门分时共享；硬连线 vs 微程序；PCSrc 第三输入
────── 以上是"能不能"，以下是"快不快" ──────
切长路径插触发器   → 流水线
结果直接递给下一拍 → 旁路；猜方向 → 分支预测
快内存放热数据     → 缓存层级（L1i/L1d 分家）
不按顺序先算着     → 乱序执行 / 重命名 / 超标量
功耗墙撞顶         → Dennard Scaling 失效，频率卡 4GHz，转多核（Amdahl 定上限）
一个核不够         → 多核 MESI / 超线程 / 内存序与屏障
进化树分岔         → GPU（吞吐）、专用加速器（算法烧成电路）、SoC 邦联
```

两个分水岭：

| 事件 | 意义 |
|---|---|
| **符号代替**（02 篇） | 物理电压 → 数学符号。从此工程师只在真值表层面思考 |
| **意外的回路**（04 篇） | 组合逻辑的禁忌（回路）恰好就是记忆。电路从此有了"过去" |

## 与主系列的对账

读完本系列，回看主系列 README 的根能力清单，每一项都能指到电路：

- **取指-执行循环** = 存储程序（00 篇）+ PC 触发器 + 译码器 + 时钟驱动（05 篇）
- **`mov` 读写** = 寄存器堆写使能 + 地址译码选内存行（05 篇）
- **中断/`syscall` 的电路本质** = 中断线 + PCSrc MUX 第三输入 + 存旧 PC（05 篇）；特权级 ring 与 CR3 涉及保护机制，留给主系列
- **流水线/缓存/乱序/多核** = 全是前四样零件的重组，无新能力（06 篇）
