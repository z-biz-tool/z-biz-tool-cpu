# cpu_work 01 · 开关：PN 结与晶体管（彻底版）

> 主线第一步：受控开关。本篇彻底版：从硅原子的化学讲起，PN 结的耗尽层电场逐层展开，MOSFET 的反型层逐伏特形成——最后 BJT/TTL/CMOS 三代电路的内战，裁决者只有一个：功耗。

## 1. 硅：四价原子的合作与叛逃

纯净硅晶体：每个原子 4 个价电子，与 4 个邻居各共享一对——**所有电子都被共价键锁着，没有自由电子 → 本征硅是接近绝缘的**（电阻率 ~2300 Ω·cm，铜是 10⁻⁶）。

**掺杂 = 在 1 亿个硅原子里换进去 1 个"叛徒"**：

- **掺磷（5 价）**：多出 1 个价电子， loosely 束缚（室温热能就够它挣脱）→ **自由电子 → N 型**（Negative，多数载流子是电子）
- **掺硼（3 价）**：缺 1 个电子 → 附近共价键出现**空穴**（等效可移动的正电荷）→ **P 型**（Positive）

浓度感：N 型掺杂 10¹⁵~10¹⁹ /cm³，硅原子密度 5×10²² /cm³——**百万分之一到千万分之一的掺杂，电阻率变化 10 万倍**。半导体工业的全部魔法都在这个灵敏度里。

## 2. PN 结：一场内部战争与停火线

把 P 和 N 贴在一起，交界面立刻发生：

```
N 区(电子多)          P 区(空穴多)
  ────┐          ┌────
      │ 扩散 → ← │        电子往 P 跑、空穴往 N 跑（浓度扩散）
  ────┤          ├────
      └─耗尽层──┘         交界处载流子"对消/复合"，剩下:
        正离子区  负离子区   ← 固定的杂质离子（不能动！）
        →→ 内建电场 ←←      阻止进一步扩散 = 停火线
```

- 扩散持续到内建电场（~0.7V 的势垒，硅）顶住浓度差——**平衡态：净流为零**
- 这条 0.7V 是怎么来的？费米能级对齐的必然结果（统计力学），记数值即可：**硅 PN 结的"关卡高度"约 0.7V**

### 单向导电的逐伏特解释

**正偏（P 接 +）**：外加电压削低关卡——0.5V 时关卡只剩 0.2V，少量载流子越境（微电流）；0.7V 关卡平，指数式爆发（e^(V/26mV)——每 +60mV 电流 ×10）。**"单向"其实是"单方向剧增"**。

**反偏（N 接 +）**：外加电压**加高**关卡 → 耗尽层变宽 → 只有少数热生载流子漏过来（nA 级漏电）。反偏到击穿电压（雪崩：电场把载流子加速到撞出新载流子，链式反应）才崩溃——**齐纳二极管就是故意用击穿做稳压**。

二极管 = 只朝一个方向剧增的阀门。**但二极管不能放大也不能控制——它只有两端，不给"第三方"说话的接口。**

## 3. MOSFET：给 PN 结雇一个"遥控员"

MOSFET = **M**etal-**O**xide-**S**emiconductor **F**ield **E**ffect **T**ransistor。结构（N 沟道增强型）：

```
        栅极 G（金属/多晶硅）
        ═════════════════
        氧化层 SiO₂（~1-5nm，绝缘！）    ← 栅极不接触硅！
    ┌─────────────────────┐
 源 S│    P 型衬底           │D 漏（N+ 重掺杂区两块）
    └─────────────────────┘
```

**工作逐伏特拆解**（V_S=0，看 V_G 从 0 拉到 2V，V_D=1V）：

1. **V_G=0**：源漏之间是 P 型衬底——只有两个背靠背的 PN 结，不管从哪边通电都有一个结反偏 → **关**。漏电流：nA 级
2. **V_G 升高（0~1V）**：栅极的正电荷隔着氧化层**静电感应**，把衬底里的电子（少数载流子）吸引到表面——表面电子浓度在涨，但还不足以反转
3. **V_G = Vth（阈值，比如 1.2V）**：表面电子浓度反超空穴——**P 型表面反转成 N 型薄层（反型层）**——源到漏之间出现一条连续的 N 型通道！
4. **V_G > Vth**：沟道加厚，V_D 施加的横向电场让电子漂移过沟道——**电流与 V_D 的关系**：小 V_D 时像电阻（线性区），V_D ≥ V_G−Vth 后沟道在漏端"夹断"——电流饱和（**饱和区，I_D ∝ (V_G−Vth)²**，平方律）

**关键：栅极与沟道之间隔着绝缘体——栅极电流 ≈ 0**。控制完全靠电场（隔空取物）。**"以压控流、控制极零功耗"——这个属性将在 §5 的内战中裁决一切。**

尺寸账：现代工艺沟道长 ~10-20nm，氧化层 1nm 级（≈5 层原子）——**栅极漏电（隧穿）成为新问题** → 高介电常数材料（high-k, HfO₂）登场：物理更厚（挡隧穿）、等效更薄（保电场控制）。

## 4. 用 MOSFET 造反相器：CMOS 的完美互补

单独一个 N-MOS 是开关，但逻辑门要"输入决定输出电平"。**反相器 = 上拉网络 + 下拉网络**，两种做法：

### NMOS 时代（1970s）：下拉用 N 管，上拉用电阻

```
VDD
 │
 [电阻 R]        ← 输出 1 时，电流从 VDD 经 R 源源不断流进导通的 N 管到地
 │
 ├── out
 │
 [N-MOS]         ← 输入 1 时导通，out 被拉到 0
 │
 GND
```

**致命伤**：输出 0 的稳态下，VDD→R→N 管→GND **常通一条电流**。百万门的芯片 = 百万个常通的小电炉——发热密度物理不可持续（8086 时代已感觉烫手）。

### CMOS（互补）：下拉 N 管 + 上拉 P 管，永远只通一半

```
        VDD
         │
      [P-MOS]   ← 输入 0 时导通（P 管是"负逻辑"：栅极低电平才开）
         │
 in ─────┼──── out
         │
      [N-MOS]   ← 输入 1 时导通
         │
        GND
```

- 输入 1：N 通 P 断 → out=0，且 **VDD 到 GND 之间无路**（P 断了）
- 输入 0：P 通 N 断 → out=1，同样无通路
- **稳态电流 = 只有漏电（nA 级）**！动态功耗只在翻转瞬间（给负载电容充放电）：**P_dyn = C·V²·f**（06 篇功耗墙的公式在此埋下）

## 5. 进化点：BJT → TTL → CMOS 内战

CMOS 不是天生赢家，它打赢了一场 30 年的战争：

| 代 | 电路 | 速度 | 功耗 | 裁决 |
|---|---|---|---|---|
| BJT 分立 | 单管放大/开关 | 快（少子器件，~GHz 潜力） | 高（导通要维持基极电流） | ECL 超快逻辑用在 1970s 大型机，但太烫 |
| **TTL**（BJT 系） | 7400 系列（1964~）：多发射极 BJT 门 | ~10ns/门 | ~10mW/门 | 1970-80s 工业标准（学生实验板上的 74LS） |
| NMOS | 电阻上拉 NMOS | 中 | 中高 | 8086/80286 时代主流——然后发热撞墙 |
| **CMOS** | 互补对 | 追上（1986 后工艺红利） | **静态≈0** | 4000 系（1968，慢、省电，先占领手表/计算器）→ 逐步吃掉 TTL 全部市场 |

**裁决逻辑**：TTL 快但每门常耗 10mW——1M 门的芯片要 10kW，**物理上不可能装进任何封装**。CMOS 静态近零，功耗只剩动态（C·V²f）——而 C 和 V 都可以随工艺缩小。**1990 年代后 CMOS 一统天下，不是因为它更快（早期更慢），是因为只有它"更省"**——06 篇的功耗墙（Dennard Scaling 失效）正是这个胜利的远期后果：省电的方案吃满市场后，规模膨胀又把功耗吃回来。

（BJT 没死：模拟/射频/超高速领域（SiGe HBT）仍在——数字逻辑战场则完全易主。）

## 6. 本篇结论

1. 掺杂百万分之一换十万倍电阻率——**半导体工业的全部杠杆在于"微量杂质对载流子的巨大控制力"**。
2. PN 结 = 浓度扩散与内建电场的平衡；0.7V 是关卡高度；"单向导通"实为"单向剧增 + 反向微漏 + 击穿"三段式。
3. MOSFET 的本质是**静电场遥控反型层**：栅极零电流、Vth 是反型门槛、平方律饱和——一切数字电路的"受控开关"岗位由它担任。
4. CMOS 的胜利公式：**上下拉互补 → 稳态无通路 → 静态功耗≈0**；P_dyn = CV²f 从这一天起成为芯片设计的最高戒律。
5. 内战裁决：速度不终极，**功耗密度终极**——TTL 输给的不是性能，是物理散热极限。
