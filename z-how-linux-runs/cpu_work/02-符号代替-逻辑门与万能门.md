# cpu_work 02 · 符号代替：逻辑门与万能门（彻底版）

> 晶体管到手（01 篇）。本篇把它抽象成符号、拼成门、证明 NAND 的万能性——并补上三个被跳过的关键课题：卡诺图（人怎么化简逻辑）、三态门（总线的前置条件）、毛刺（真值表对但电路错的陷阱）。

## 1. 抽象：从电路到符号

工程师从不看晶体管级电路讨论逻辑——**抽象层**在此建立：

| 层 | 对象 | 单位规模 |
|---|---|---|
| 器件层 | MOSFET | 10nm |
| 门层 | NAND/NOR/INV | 4~20 管 |
| 模块层 | 加法器/MUX/触发器 | 几十门 |
| 系统层 | ALU/寄存器堆/控制器 | 万门 |

**抽象的代价与回报**：门层看不到晶体管 → 丢失时序细节（本篇 §5 毛刺就是这个漏洞）；换来的是可组合性——**只要每级门的输入输出都是干净的 0/1，就能无限堆叠**。而"保持干净"的功臣是——

### 再生链：数字信号的自我修复

01 篇 CMOS 反相器有个隐藏能力：**增益**。输入 1.2V 它输出 0V，输入 1.3V 它输出 0V——中间值的模糊被**放大推向两端**：

```
输入模糊 1.3V → 门输出干脆的 0V → 下一门再修复 → …
噪声容限：输入可在 [0, V_IL] 当 0，[V_IH, VDD] 当 1——中间禁区约 0.8~1.2V
```

**这是数字 vs 模拟的分水岭**：模拟信号每过一级电路就"脏"一点，数字信号每过一级门都被**再生**一次。几十亿门串联成为可能，全靠每级的放大整形。噪声容限越宽（01 篇二进制裁决的第 2 条），堆叠层数可以越多。

## 2. 三种基本门的晶体管级实现（CMOS）

### 反相器（1+1 管）

01 篇已画。F = NOT A。

### NAND（2 输入，4 管）——CMOS 的"原生"门

```
        VDD
     ┌───┴───┐
   [P-A]   [P-B]      ← 上拉：P 管"负相"——A、B 任一为 0 就有一条 P 管导通
     └───┬───┘
         ├──── out = NOT(A AND B)
       [N-A]
         │          ← 下拉：N 管"正相"——A、B 全 1 才串联通路到地
       [N-B]
        GND
```

- A=B=1：两 N 串联通 → out=0；两 P 全断 → 无上拉——干净
- 任一为 0：对应 N 断（下拉断路）+ 对应 P 通（上拉通路）→ out=1
- **为什么 NAND 是 CMOS 的原生门？** N 管天然串联（AND 形）、P 管天然并联（OR 形，负逻辑）——串联下拉 + 并联上拉恰好构成 NAND。做 AND 反而要多一级（NAND+INV）。

### NOR（2 输入，4 管）

镜像结构：P 串联、N 并联。同样"原生"。

**规律：CMOS 里，串联/并联互换 + P/N 互换 = AND/OR/INV 三种运算互换**——德摩根定律的电路化身：`NOT(A·B) = Ā+B̄`（NAND 输入取反 = OR），电路与代数在同一时刻写成。

## 3. 万能门证明：NAND 造宇宙

香农式论证——用 NAND 拼出其他三种，则一切布尔函数皆可拼（其他门都是这三种的组合）：

```
NOT:  a ──┬─[NAND]── ā
          └──────┘          （两输入并同一个信号）

AND:  a,b →[NAND]→ x →[NAND(自并)]→ a·b
                    （NAND 后再 NOT：NOT(NOT(a·b))）

OR:   ā = NAND(a,a)，b̄ = NAND(b,b)
      OR = NOT(AND(ā,b̄)) = NAND(ā,b̄) = NAND(NAND(a,a), NAND(b,b))
      ——德摩根直接给出：3 个 NAND 拼 OR

XOR:  a XOR b = NAND(NAND(a,NAND(a,b)), NAND(b,NAND(a,b)))
      ——4 个 NAND；读者可用真值表验证（4 行全对）
```

数一数成本：**NOT=1 个门、AND=2、OR=3、XOR=4**。综合工具（00 篇 EDA）输出的网表里 NAND/NOR 占比过半——**这就是原因：原生门 + 万能性，双料便宜**。

## 4. 进化点 I：组合逻辑三铁律 + 卡诺图

用门拼"无记忆"的组合电路（输出只看当前输入），三条纪律：

1. **无环**：输出不能绕回输入——有环就变成时序电路（04 篇）
2. **信号有起点**：每个门输入必须来自输入端或某门的输出
3. **等价真值表**：电路对不对，唯一标准是真值表逐行相等

**但"对"不等于"好"**：同一个真值表可以有十种电路，门的数量差 10 倍。化简的数学工具——**卡诺图**（1953，Maurice Karnaugh）：

把真值表排成 2D 网格，**相邻格子的输入只差一位**（格雷码排列），于是"能圈在一起的一组 1"必然对应"消掉一个变量"：

```
AB\CD 00 01 11 10
  00 | 1  1  0  0 |     圈 1：A=0,B=0 的两格 → F 含 ĀB̄，C、D 被消掉
  01 | 1  1  0  0 |     圈 2：C=0 的整列四格 → F 含 ĀC̄……
  11 | 0  0  1  1 |     真值表 8 个 1 → 化简成 3 项 6 个字面量
  10 | 0  0  1  1 |     （原始积之和要 8 项 32 个字面量）
```

**本质：布尔代数的化简法则（吸收律等）被"几何相邻"可视化**——人肉时代的 EDA；今天综合软件做同样的事（ espresso 算法等），只是规模是百万项。

## 5. 进化点 II：三态门——总线的入场券

普通门输出只有 0/1 两态。总线（多设备共线）需要第三态：**Z（高阻）= "我把嘴闭上了"**——输出级与导线物理断开。

```
      VDD
    ┌──┴──┐
    [P]    ─┐
 out ────────┤ 三态缓冲：EN=1 时照常输出；EN=0 时上下两管全断 → Z
    [N]    ─┘
    └──┬──┘
      GND
```

- 输出级就是 CMOS 反相器的上下管对，**EN=0 时两管同时被关死**——既不拉高也不拉低，输出浮空
- **只有三态（或 MUX，mini 01 的现代替代）让"多设备共享一根线"成为可能**：任一时刻只有一个设备驱动，其余置 Z
- 五个敌人：两个设备同时驱动且电平相反 = **输出冲突（总线争用）**——大电流直通 VDD 到 GND，烧芯片。总线的全部纪律（仲裁、时序）都是防这个（mini_machine 01）

## 6. 进化点 III：毛刺（Glitch）——真值表对，电路错

理论的黑暗角落：组合电路**理论上是稳态数学，物理上是传播延迟的战场**。

实例：`F = A·Ā`（代数上恒为 0，永无毛刺风险？错）——用两个独立门实现：

```
A ────┬────────[AND]──── F
      └─[NOT]──┘
        (延迟 2ns)  (延迟 3ns)
```

A 从 1 跳 0 的瞬间：NOT 的输出**要过 2ns 才变成 1**——这 2ns 里 AND 的两个输入是（A 下降沿已到=0 还没完全传播？）——精确时序：t=0 时 A=1→0，AND 输入 1 为 0；但 NOT 输出仍是旧的 0（还没翻到 1）——等等这个组合无毛刺。换会出毛刺的经典例：`F = A·B + Ā·B`（代数恒等于 B）——A 翻转时，`A·B` 项和 `Ā·B` 项**交接棒**：一个已经掉了、另一个还没起来 → **B=1 期间 F 短暂跌 0 又弹回 1**：

```
A:  ────┐   ┌────
        └───┘
F:  ────┐┌┐ ┌────   ← 中间那个细脉冲 = 毛刺（ glitch ）
        └┘└─┘        宽度 ~ 一个门的传播延迟
```

- 后果：若 F 接的是**异步计数器/锁存使能**，这个 ns 级脉冲就会被误当成时钟沿——**系统性地、随机地、极难复现地出错**
- 三个治法：①冗余项覆盖（卡诺图上把相邻的两个 1 圈用冗余圈连起来——代数上"多余"，时序上救命：`F = A·B + Ā·B + B·B`…即加 B 项，交接棒期间 B 项托底）；②时钟化（采样只在时钟沿，毛刺落在沿间即无害——04 篇同步设计的核心动机）；③后端工具做 glitch 猎杀

**洞见：组合逻辑的正确性有两份证明——真值表（稳态）+ 时序（暂态）。新手只交第一份。**

## 7. 本篇结论

1. 抽象分层 + **再生链**（每级门放大整形）= 数字电路无限堆叠的许可证；噪声容限是堆叠深度的预算。
2. CMOS 原生门是 NAND/NOR（串联下拉+并联上拉的天然形状），AND/OR 都要加一级反相。
3. **NAND 万能**（NOT=1、AND=2、OR=3、XOR=4 个门）——整个数字宇宙从一种门可拼出；EDA 网表 NAND 遍地是这条证明的工程回声。
4. 卡诺图 = 用几何相邻做布尔化简——人肉 EDA；三态门 = 输出第三态 Z，总线共享的物理前提，输出冲突是它唯一的天敌。
5. **毛刺 = 稳态正确、暂态出错**：传播延迟让代数恒等式在物理上短暂失效——同步设计（04 篇）的第一动机。
