# cpu_work 04 · 意外的回路：触发器与时钟（彻底版）

> 组合逻辑的世界只有"现在"（02 篇三铁律禁环）。本篇彻底版：回路怎么从"违规"变成"记忆"、SR 锁存器四种状态逐个分析、主从结构怎么驯服毛刺、T_clk 公式的全推导、亚稳态的概率账——"意外"二字的含义在此揭晓。

## 1. 意外的回路：1 bit 记忆是怎么被"不小心"发现的

02 篇铁律一：组合逻辑不能有环。但如果**故意**把两个非门首尾相接呢？

```
   ┌──[NOT]──┬──→ Q
   │         │
   └──[NOT]──┴──→ Q̄
```

分析这个环上的电压：设中间电压 V 稍高于逻辑 1/2——经过两级放大（增益>1）返回来**更高**——正反馈一路推到 VDD 顶死。反之推到 GND。**两个稳定点，中间点不稳定**（01 篇 PN 结平衡的镜像：这里没有平衡点，只有两个"落井"）。

这就是 **1 bit**：落在哪个井 = 存的是 0 还是 1。**没有参与任何运算、没存任何"信号源"——状态是电路自己的**。双稳态（bistable）诞生。

**但这个纯环没有输入**——你没法让它换井。历史注脚：这个结构 1918 年就由 Eccles & Jordan 用真空管做过（触发器多谐振荡器）——**触发器比数字计算机更老**；1945 年代它只是没被叫作"存储器"。

## 2. SR 锁存器：给环装两个把手

把两个非门换成两个**或非门**（NOR），各引出一个输入：

```
  S ──[NOR]──┬── Q
       ↑     │
       └──┐  │
          │  └──[NOR]── Q̄
          │       ↑
          └───────┼── R
```

**四种输入态逐个分析**（NOR：任一输入为 1 则输出 0）：

| S | R | Q | 状态 |
|---|---|---|---|
| 0 | 0 | **不变** | 保持——两个 NOR 都只剩反馈输入，环自己锁着（第 1 节的纯环）|
| **1** | 0 | **1** | 置位 Set——S=1 强制上面的 NOR 出 0 → Q̄=0 → 下面 NOR 两入全 0 → Q=1 ✓ 自洽 |
| 0 | **1** | **0** | 复位 Reset——对称地推另一口井 |
| **1** | 1 | **禁止!** | 两个 NOR 都被强制出 0 → Q=Q̄=0——**违反互补**；且同时撤销时，两路竞争结果取决于门的微小延迟差——**结局随机**（竞态） |

**SR 锁存器 = 有把手的井**：S 把球推进井 1，R 推回井 0，两手都不动球就不动。1 bit 可写存储器诞生——**这是人类第一次用门电路实现"写"这个动作**。

（NAND 版本：低有效 S̄/R̄，全 1 保持，00 禁止——逻辑对偶，结构相同。）

## 3. 电平触发的灾难：透明锁存器

给锁存器加"写使能"：EN=1 时 S/R 才有效。问题：**EN=1 的整个期间，锁存器是"透明"的**——输入怎么变，输出跟着怎么变（不像触发器，像一段导线）。

灾难场景（03 篇毛刺的续集）：

```
组合逻辑算出数据 → EN=1 的窗口里数据还在抖（毛刺/未稳定）
→ 锁存器把中间态也收了进去 → 存错
```

**根因：EN（电平）与数据（时序）之间没有唯一的采样时刻**。需要一种"只在某个瞬间看一眼"的结构——

## 4. 主从 D 触发器：两个锁存器互相看门

主从结构（master-slave），用两个电平锁存器 + 相位相反的时钟：

```
D ──[主锁存器 EN=CLK]──[从锁存器 EN=CLK̄]── Q

CLK=1：主开门（跟随 D），从关门（Q 不动）   ← 采集中，外界看不见
CLK=0：主关门（锁住刚才那一眼），从开门输出 ← 交付
```

**效果：输出只在 CLK 下降沿变化一次**——任何时刻输入怎么抖，只有 CLK 从 1→0 瞬间主锁存器锁住的那个值会被交付。**电平 → 沿**，一步之差，数字设计的天与地：

- 毛刺防治（02 篇 §6）：数据在沿间抖 → 沿上采到的是稳定值
- 全系统节奏统一：所有触发器在同一沿采样——**同步设计的起点**

现代工艺用传输门构成的正沿 DFF（CLK 上升沿采样）物理细节不同，**契约完全相同：输出只在沿变**。D 输入（Data/Delay）直通 Q——SR 的"禁止态"被结构消灭（D 只有一个入口）。

## 5. 时序三参数：T_clk 公式的全推导

沿采样的契约下，数据到达必须"赶上沿"。三个参数（真实器件手册都有）：

| 参数 | 定义 | 物理来源 |
|---|---|---|
| **T_cq** | 沿到 Q 更新的延迟（~100ps） | 采样开关切换 + 主从级联传播 |
| **T_setup** | 数据必须**早于**沿稳定的最小时长（~50ps） | 主锁存器的采样回路需要时间把新值"锁定"进环（正反馈建立需要几级延迟） |
| **T_hold** | 数据必须**晚于**沿继续维持的最小时长（~20ps） | 沿切换瞬间主门没完全关死，输入若立刻变，新值可能"漏"进同一拍（hold 违例没有软件解法——纯电路布线问题） |

**推出全系统的心跳公式**（两个触发器之间隔着一段组合逻辑 T_comb）：

```
本沿发出数据（T_cq 后到达线端）→ 穿过组合逻辑（T_comb）
→ 必须在下一个沿之前 T_setup 到达：

T_clk ≥ T_cq + T_comb + T_setup
```

**这张不等式就是 CPU 的物理宪法**：

- 03 篇算过行波加法器 128τ——T_comb 太大 → **频率被组合逻辑最坏路径钉死**（超前进位就是为了让 T_comb 缩短）
- 06 篇流水线：把长 T_comb 切成几段、每段塞触发器 → 每段 T_comb 变短 → T_clk 变小——**流水线的物理本质就是用沿切分 T_comb**
- cpu_work 05 的"译码器+寄存器堆+ALU"每两个寄存器之间的路径都要过这个不等式的验收（EDA 工具的 STA 静态时序分析就是自动验不等式）

## 6. 进化点 I：JK、T、计数器与移位寄存器——触发器的家族

**JK 触发器**：SR 的禁止态被重新定义——J=K=1 时**翻转**（toggle）：

| J | K | Q(next) |
|---|---|---|
| 0 | 0 | 保持 |
| 0 | 1 | 0 |
| 1 | 0 | 1 |
| **1** | **1** | **翻转** |

主从结构消灭了 SR 的竞态（沿采样下不会两头同时冲）。JK 的"翻转"衍生出 **T 触发器**（T=1 每${1}$拍翻一次）——

**计数器 = T 触发器串**：最低位每拍翻、进位时次低位翻……

```
T0（每拍翻）→ 其 Q 上升沿当 T1 的时钟 → 二分频链
Q0: 01010101
Q1: 00110011   ← Q0 的二分频
Q2: 00001111   ← 四分频 —— 三位二进制计数器，顺便每一级都是÷2 分频器
```

**移位寄存器**：D 触发器串糖葫芦，共时钟，每拍整体右移一格——串行↔并行转换（UART 的 TDR→TX 就是移位寄存器，mini_machine 03）、乘法的部分积对齐（03 篇）都靠它。

**洞见：触发器的"沿采样"契约 + 少量拼接 = 计数器/分频器/移位器/寄存器堆**——同一块砖的不同砌法。

## 7. 进化点 II：时钟树与偏斜（skew）

"所有触发器同沿动作"是个理想——物理上时钟从晶振出发，要**分发**到芯片上亿个触发器（mini_machine 02 的时钟树）：

```
         PLL
          │
      ┌───┴───┐
   ┌──┤ H-tree ├──┐        H 树/鱼骨布线：等长走线让到各叶节点的
   │  └───────┘  │        线延迟尽量相等
 [FF 组A]   [FF 组B]
```

- **skew（偏斜）**：各触发器实际看到的沿有时间差（10-50ps 级）——§5 的不等式两边都要打折：发送端沿晚了/接收端沿早了都吃掉预算。**T_clk 实际 ≥ T_cq+T_comb+T_setup + skew**
- 更阴险的：**时钟功耗占总功耗 30-50%**（每拍全芯片的时钟线都在翻转）——**门控时钟**（clock gating：不用就关枝干）是省电第一招（mini 02）
- 工艺对策：时钟树综合（CTS）是 EDA 后端最重的步骤之一——**"让十亿个听众同时听见拍子"是物理级合唱难题**

## 8. 进化点 III：亚稳态——概率不被归零

异步信号（外部按键、别的时钟域）直接进触发器，可能撞上最坏情况：**数据恰好在沿前后 T_setup~T_hold 窗口内变化**——主锁存器的正反馈还没建立完成就被打断，输出卡在**中间电压**，且**不确定何时才能掉进某个井**（可能 ns，可能 μs，可能"永远"理论上）。

**概率账**（MTBF——平均无故障时间）：

```
MTBF = e^(T_recovery/τ) / (f_clk × f_data × T_window)
τ ≈ 反馈环的时间常数（工艺相关 ~20ps）
T_recovery 每多给 1 个门延迟，MTBF 乘 e^（≈×若干千倍）
```

**无法归零，只能压概率**：两级同步器（两个 DFF 串接，第一级的"卡住"有一整拍时间自行衰减）→ MTBF 从小时级变宇宙年龄级。跨时钟域的一切规矩（握手、异步 FIFO、格雷码计数）全部围着亚稳态转。**数字世界的"确定论"建立在概率被驯服到工程可忽略的边界上**——这是 0/1 哲学最深的一道裂缝。

## 9. 本篇结论

1. **双稳态回路 = 1 bit**：正反馈造两个"井"，状态是电路自己的——记忆不需要任何"介质"隐喻，它就是增益与反馈。
2. SR 锁存器给井装把手（保持/置位/复位/禁止四态）；电平透明是灾难根源；**主从双锁存 = 沿采样契约**，一跃解决毛刺与全局同步。
3. **T_clk ≥ T_cq + T_comb + T_setup 是 CPU 物理宪法**：频率被最坏组合路径钉死；流水线 = 沿切分 T_comb（06 篇的物理根）。
4. JK/T/计数器/移位寄存器 = 同一块砖的拼接学；时钟树与 skew 提醒"同时"是布线工程；**亚稳态是概率裂缝**，两级同步器把它压到宇宙年龄级。
5. 到此，"算"（03 篇）与"记"（本篇）都齐了——05 篇把它们合体成 CPU。
