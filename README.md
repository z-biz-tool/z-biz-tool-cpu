# z-biz-tool-cpu

数字电路与 CPU 构建沙盒：从一颗 NAND 门开始，逐级搭到能跑汇编程序的 16 位 CPU。

纯 TypeScript 内核 + React 画布编辑器，无后端、无外部仿真库，全部逻辑自己实现；内核可在 node 下 headless 运行，判题与自检全部走脚本。

## 快速开始

```bash
npm install
npm run dev        # http://localhost:5173
npm run verify     # 内核自检（仿真 / 判题 / 参考 CPU）
npm run build      # tsc --noEmit && vite build
```

| 脚本 | 说明 |
| --- | --- |
| `npm run dev` | 启动编辑器 |
| `npm run build` | 类型检查 + 生产构建 |
| `npm run typecheck` | 仅 `tsc --noEmit` |
| `npm run verify` | 41 项内核自检：位宽推断、仿真收敛、31 关参考解答、7 段示例程序 |
| `npm run format` | Prettier 格式化 |

## 功能

### 电路内核
- 29 种内置元件，覆盖 8 类：输入输出、常用工具、逻辑门、运算器、选择器、总线、时序、存储。
- 网络表展平 + 位宽单调推断：总线位宽由驱动端自动推导，多驱动报 error、定宽截断报 warn，拓扑诊断实时显示在属性面板。
- 事件驱动的逐步仿真器：`step()` 按时钟「拉高 → 稳定 → 上升沿 → 稳定 → 拉低」推进，支持探针、日志、状态快照与回滚。

### 画布编辑器
- 放置、连线、框选、旋转/镜像、复制、删除，子电路双击进入、面包屑返回。
- 滚轮缩放（0.25×–3×），中键/右键/Alt 拖动平移，F 一键适配视图。
- 导线支持总线样式与实时电平着色，元件引脚值悬浮可见。

### 子电路封装
- 选中若干元件按 `G` 打包成自定义元件：内部连线隐藏，跨越边界的导线自动提升为对外引脚。
- 封装体可反复放置、可嵌套、参与位宽推断与花费统计，`boundaryOf` 计算对外引脚。

### 关卡挑战
- 5 层 31 关，从逻辑门到微程序控制器，每关含任务说明、知识点讲解、提示、基准花费与参考解答。
- 判题引擎按测试向量逐条比对输出，记录通过项/花费/子电路数；进度、成就（10 枚）、加速档位写入 localStorage，设计自动存档。

### 汇编与 CPU
- Z16 指令集：16 位定长指令字，`[15:12] OP / [11:8] A / [7:4] B`，双字形式携带 16 位立即数；R0–R5 通用寄存器，R6=SP，R7=LR；标志位 Z/C/N。
- 汇编器支持标号、`.equ`、`.str`、表达式与反汇编，输出机器码列表（listing）。
- 参考 CPU 由库内元件搭建（87 元件 / 222 连线），含取指、译码、ALU、寄存器堆、控制信号与停机状态机；一键装入画布即可逐级观察。
- CPU 面板：PC/IR/IMM/状态/控制字/标志/寄存器组/存储实时可视化，支持单拍、连跑、跑到停机、复位与终端输出。
- 存储体系：RAM/ROM 可被程序镜像装载，覆盖栈、片选译码、哈佛结构、查表输出等关卡。

## 目录结构

```
src/
  core/        数据模型、网络表、位宽推断、仿真器、序列化、元件注册表
  asm/         指令集定义、汇编器/反汇编器、示例程序
  cpu/         参考 CPU 设计与程序运行器
  challenges/  关卡数据、参考解答、判题与进度存储
  editor/      画布渲染、交互 store、工具栏、元件库、属性面板、各功能面板
scripts/       内核自检与调试脚本（headless 运行）
```

## 说明

本项目为独立的教学/沙盒玩具，指令集、关卡文案、参考解答与界面均为原创实现。
